# 游戏机制 SVG

## 保存位置

成品统一保存到当前 FlatWorld 项目根的 `游戏机制SVG文件夹/`，本项目路径为 `D:/_Unity/_UnityProject/FlatWorld/游戏机制SVG文件夹/`。这些图是游戏项目的长期资产，不要只留在临时目录或聊天附件里。

按机制需要建立子目录，文件名直说主题，例如 `环境/风力推动与质量.svg`；已有同主题图时优先更新，并在目录的 `README.md` 中补充入口。

## 创建方式

- 先看相关代码、配置或用户确认的规则，再决定用流程图、关系图、曲线还是动画；规划和假设简单注明。
- 直接编写 SVG，中文说明配合箭头、颜色和必要的数值、单位，重点让机制一眼能看懂。
- 时序、运动和状态变化适合 SVG/CSS 动画；需要按钮、滑条时，可在同目录附上 HTML。
- 尽量把图形、样式和动画放在文件内，方便离线打开和长期复用。
- 保存后检查 SVG 能解析、引用路径有效，汇报时给出项目内文件链接；玩法效果由用户验收。
