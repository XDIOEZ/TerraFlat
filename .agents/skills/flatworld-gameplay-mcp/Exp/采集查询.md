# 采集查询

- `source=drops` 查可拾取散落物；生态点的 `removed=true` 也可能表示已转交掉落服务，不等于玩家已经捡走。
- `source=runtime` 查询世界实体，排除手持表现；库存与手持身份读 `gameplay_observe`。
- `source=terrain` 可用 `biomeId` 在已加载地形中筛选群系，先筛选再取最近坐标；查不到不代表整张地图没有该群系。
- `source=ecology` 的 `hp` 直接读取已激活自然物 ECS 实时生命；未激活、已删除或无生命组件时为 null。`gameplay_observe.player.carryCapacity` 给出背包与快捷栏合计重量、体积和上限。
- `player.hand` 是鼠标搬运库存；攻击能力读 `player.equippedWeapon`。`drag.handled` 只表示发送事件，操作后须核对库存；动作 `ok=false`、内层 `success=false` 都是失败。
- 重复拾取从项目根目录运行 `python .agents/skills/game-developer-loop/scripts/collect_drop.py <itemId>`，按实际库存增量判成功；桥接断开只报错，查询现场后再决定动作，不盲目重放。
- `equippedWeapon.backend` 区分普通冷兵器与动画武器；动画后端未公开只读攻击冷却，`canAttack=null` 表示未知，不能当作攻击被禁用。附近实体观察也排除 `InHand`，装备仍由快捷栏字段读取。
