# FlatWorld 高清角色立绘规范

## 资产定义

角色立绘（`Portrait`）是供对话、角色信息、任务或其他 UI 展示使用的高清透明人物图，不是运行时场景角色动画，也不是用于探索多个方案的概念草图。

| 类型 | 主要用途 | 默认视角与构图 | 美术处理 | 文件命名 |
| --- | --- | --- | --- | --- |
| `Portrait` | 对话、角色页、任务及 UI 人物展示 | 平视、竖版、全身完整可见 | 高完成度 2D 人物插画、透明背景 | `<Name>_Portrait_FullBody_<Expression>.png` |
| `Concept` | 探索、确认或迭代设计 | 按设计需要，可包含辅助视图 | 高清设计源，不承诺直接进入 UI | `<Name>_Concept_HighRes.png` |
| `Sprite` | 场景运行时移动与动画 | 俯视像素画，按方向和动画网格 | 使用 `flatworld-pixel-art` | `<Name>_<State>_<Direction>.png` |

三类资产可以共享角色身份锚点，但不得直接互相替代。禁止把 Portrait 缩小后当作 Sprite，也禁止把放大的 Sprite 当作正式 Portrait。若用户实际需要 Concept 而非 Portrait，应明确重新分类，不套用正式 UI 交付承诺。

## 表现效果

- 允许参考用户提供图片的画风：高完成度二次元游戏角色立绘、清楚精致的面部、精细而受控的线稿、赛璐璐为主的分层明暗、局部柔和材质塑造、复杂但层级清晰的服装与配件结构。
- 画风参考约束精细度、轮廓可读性、材质表达、细节密度和完成度；不得复制参考人物的身份、脸、发型、服装款式、武器、配色、装饰符号、姿势专属道具或世界观。
- 保留 FlatWorld 已确认角色设计的核心身份：年龄感、体型、头发轮廓、面部印象、服装结构、主配色、标志配件和职业气质。
- 允许把像素图中被压缩的结构合理展开，例如明确腰包扣具、布料拼接与皮革层次；新增细节必须能解释原设计，不能借机重做角色。
- 默认使用清爽、克制的材质塑造：哑光通透皮肤、归组的头发高光、少而明确的布料褶皱、稀疏皮革边缘高光和小面积金属亮点。避免油亮皮肤、蜡感面部、塑料头发、湿亮皮革、靴面大块反光、过量暖黄罩染和密集碎褶皱。
- 用户要求“平涂”时切换为严格平涂模式：每种主要材质以一个固有色加一档硬边阴影为主，仅在必要处使用一小块纯色高光；禁止柔和渐变、喷枪过渡、绘画笔触、表面纹理、环境光晕或多级体积塑造。
- 不要求像素画的颜色上限、硬 Alpha、1 像素描边或大头短身比例；也不使用照片写实、光滑 3D 渲染或厚重油画覆盖角色设计。

### 独立游戏作者感与去默认生成感

- “高完成度”不等于所有局部都精细、材质都写实或表面都布满磨损。先确定一个可复述的形状语言、一个主色块和少数身份焦点，再主动省略其余信息。
- 角色需要至少两个有因果关系的非对称身份点，例如不齐的眉眼、偏斜的鼻梁、不同高度的卷袖、旧伤或偏置衣摆；不得只靠随机伤疤、污渍和皮革划痕制造“独特”。
- 体型应服务人物生活与职业。普通劳动者优先表现重心、肩背习惯、腰腹和手臂使用方式，避免默认套用倒三角健身体型、英雄站姿、时装姿势或对称展示姿势。
- 给细节设预算：默认只保留一个职业道具、一个叙事磨损或修补点、一个小面积材质亮点。相同语义不重复堆叠，例如锤子、巨型手套、护腕、钢头靴和多条皮带不同时用于反复说明“铁匠”。
- 使用明确的视觉层级：脸部轮廓、服装大形和职业道具承担识别；次要区域允许大面积不画褶皱、不加纹理、不做多级明暗。缩略图仍靠形状与色块辨认，而不是靠高清表面噪声。
- 若用户反馈“一眼 AI”，优先重做设计取舍，而不是继续润色旧图。检查并移除默认俊美脸、左右对称、均匀细节密度、随机材质噪声、配件堆叠、混合渲染语言和过度电影光照。

## 构图与视角

- 默认摄像机与人物胸腹高度接近平行，使用自然平视；禁止俯视、仰视、鱼眼、倾斜镜头和强透视缩短。
- 默认展示一个角色的完整全身，头顶、发梢、手、服装下摆、标志装备和双脚全部位于画布内。
- 使用自然站姿或表达职业气质的轻度动态站姿；动作不得遮挡面部、服装主结构或关键身份配件。
- 人物默认位于画布中央，四周保留约 `8%-12%` 安全留白，避免 UI 缩放或裁切时损伤轮廓。
- 默认竖版画布，优先 `3:4` 或 `2:3`；最终尺寸由 UI 消费方决定。未给出消费尺寸时生成足够高清的竖版源图，不虚构具体 UI 像素契约。
- 不添加场景、底座、边框、文字、Logo、光环、地面、接触阴影或投影。

## 身份继承与参考职责

在提示词中逐张标注输入图职责：

- `identity reference`：决定角色是谁，锁定头发、脸部印象、体型、服装结构、配色与配件位置。
- `art-style and presentation reference`：只决定插画语言、线稿精度、材质表达、构图、细节密度、光影层次和完成度，不决定角色内容。
- `pose reference`：仅在用户明确提供时决定动作，不得覆盖身份锚点。

参考冲突时，身份参考优先于画风与表现参考。若用户只提供运行时像素角色，先列出可观察到的身份不变量，再对缺失细节做最少量、可解释的高清化。

## 透明背景与边缘

- 最终交付优先为带 Alpha 的透明 PNG，保留头发、布料和细小配件的干净边缘。
- 使用内置 ImageGen 时遵循系统 `imagegen` Skill：先生成完全平坦的纯色色键背景，再本地去除并检查透明边缘。
- 色键背景不得包含渐变、纹理、地面、反射、投影或光照变化；色键颜色不得出现在角色主体中。
- 立绘允许平滑 Alpha。若发丝或半透明布料导致色键去除无法可靠验收，必须按 `imagegen` Skill 的透明输出回退规则处理，不得伪称完成。

## Unity 导入边界

- 立绘仅在用户要求接入 UI 时配置 Unity；单纯生成立绘不主动创建 Prefab、Animator、SO 或 UI 代码。
- UI 立绘使用适合缩放的平滑过滤、启用 Alpha、关闭 Mipmap，并依据目标平台设置无损或高质量压缩。
- 不设置运行时像素角色的 `PPU 16`、Point 过滤、底部中心世界 Pivot 或 Sprite Sheet 切片。
- UI 具体锚点、最大显示尺寸、图集和 Addressables 规则必须检查实际消费方后决定。

## 验收清单

- 资产被明确标记为 `Portrait`，命名未与 Concept 或 Sprite 混淆。
- 摄像机自然平视，单人全身完整，头顶与双脚均未裁切。
- 缩略到预期 UI 大小时，面部、主配色、服装大形和职业配件仍能辨认。
- 与身份参考一致；画风接近表现参考，但没有继承参考人物的身份设计。
- 衣物、头发、肢体和装备遮挡合理，没有多余肢体、断裂配件或无法解释的新物件。
- 背景透明、边缘干净，无色键残留、底座、文字、水印、投影或 UI 边框。
- 最终报告画布尺寸、主体边界、透明度、身份不变量、参考职责、提示词与必要人工观感检查。
