# TPS 与画面表现边界核查

## 正式执行顺序

```text
Update：输入采样 → 游戏时钟累计 → 0～4 次逻辑 Tick
Tick：玩法/动作 → 原生物理 → 接触/乘员提交 → SnapshotCapture
LateUpdate：逐帧表现 → 镜头显示锚点 → 镜头 → 屏幕 UI
Render：复制视觉 → 应用插值姿态 → 保留插值完成排序 → 绘制
```

`EveryFrame` 是历史枚举名，在模块调度中表示每个基础逻辑 Tick，并非每个显示帧。新增输入用 `ModInputUpdate`，新增纯表现用 `ModRenderUpdate`；碰撞、数值、冷却和存档不得从后者推进。

## 本轮定位与处理

| 链路 | 原耦合 | 修改后的边界 |
| --- | --- | --- |
| 模块调度 | 输入与显示共享回调，显示资格受模拟权威约束 | 输入、模拟、显示三条通道与独立计数，注册令牌/代际校验共用 |
| GO 实体 | 渲染时记录运动，查询位置会修改历史，只补平移 | 物理后提交根和子节点姿态；位置、旋转、缩放由只读历史补间 |
| 显示排序 | 排序前再次复制源姿态覆盖本帧插值 | 最后同步保留并重施同一显示变换 |
| 手动物理 | 部分物品仍使用 Unity 原生插值 | Script 模式统一 None；游戏快照独占补间，自动物理模式保留模板配置 |
| 玩家与载具 | 镜头/气泡各取不同姿态，乘员在 LateUpdate 改刚体 | 镜头与 UI 共享显示姿态，乘员在 AfterPhysics 提交；车轮按显示位移滚动，座位朝向按 Tick 提交 |
| 持握、转向、武器 | 显示帧改命中姿态，动画窗口由 AnimatePhysics 推进 | 输入仅采样目标；逻辑 Tick 提交持握/转向与动作，武器按作者采样精度检查短伤害窗；显示副本补间 |
| ECS 生物 | 绘制时采样、基础 Tick 与实际低频脉冲混淆 | 使用每个实体实际 MotionSampleTime 提交位置/高度，绘制只读 |
| 轻量掉落物 | 游戏时间记录却用 Unity 时间求值，并叠水流补间 | 单一游戏表现时钟，位置/旋转/高度/沉没显示值统一采样 |
| 血条、氧气条、鱼线、拖尾 | 跟随物理根或局部动作原始节点 | 共用显示矩阵与挂点；世界锚定子节点反投影，避免父级重复插值 |
| 弓蓄力 | 显示只看到逻辑进度台阶 | 仅预测值类型副本的进度，发射强度、体力不变 |
| 昼夜与阴影 | 每帧刷新仍读取阶梯式逻辑时间 | 显示时只读投影 Tick 余量；真实环境光层、日期、事件与存档仍用权威时间 |
| TPS 切档 | 清空时间余量导致表现时间倒退 | 保留已经累计的游戏秒，不改变 Unity FixedUpdate 设置 |

## 保留已有独立后端

太空船体/乘员已经有自己的模拟快照和表现时钟；网络快照由网络端自己的时间轴消费，不叠加另一层 TPS 补间。机械关节/输送带的持续相位、单 Sprite 动画、粒子/Shader、界面渐隐原有逐帧表现入口继续保留。离散状态、资源计数、伤害结果不是连续姿态，不通过插值伪造中间业务状态。

## 生命周期与一致性

传送主动丢弃旧历史；代际、场景、世界或视图所有权变更重建快照。不同频率的模拟可以使用实际采样时间；同帧多 Tick 逐次提交，不只记录最终位置。显示位置查询次数不改变模拟、碰撞、事件或存档。已有逐帧拥有者修改的姿态通道直接显示，避免重复插值。

## 验收入口与边界

`rendering_visual_interpolation` 验证多 TPS/FPS 组合、完整姿态、纯读取、子节点副本隔离、多步追赶与切档余量；`item_runtime_rules` 验证三通道独立及生命周期。`player_gameplay` 新增 `independent_presentation_frames`：实际渲染回调观察 30 TPS、0.25 倍慢放下，逻辑不变时显示继续移动，核对镜头目标/绘制副本一致及刚体不被改写。慢放用于在较低性能 Editor 中形成明确 Tick 间隙，不把目标120FPS当作实际达到120FPS。

武器与载具分别用 `combat_gameplay` 和 `player_bicycle` 走真实流程，钓鱼/掉落/时间使用原系统回归。代码核查、数学采样、真实场景与连续画面验收各自报告；不能把单张截图、规则通过或仍未执行的双客户端/移动端案例当作全部视觉已验收。
