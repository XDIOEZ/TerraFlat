# FlatWorld 运行时像素美术风格指南

## 参考优先级

从高到低使用以下参考；冲突时服从更高优先级：

1. `Assets/6_Art/Generated/<System>/` 中与目标同类别、且实际已在游戏中使用的项目素材：绘制前打开具体贴图查看，优先约束视角、世界尺度、轮廓、像素簇、描边观感、配色、明暗与材质表达。系统目录内不足时再参考项目其他目录的同类别素材；物品参考物品，工具参考工具，树木参考树木/植被，建筑参考建筑，不得拿跨类别素材强行统一尺寸。
2. `.agents/skills/flatworld-pixel-art/assets/merchant-style-anchor.png`：仅用于角色类素材理解角色比例、服装大形、配色关系与身份配件。
3. `.agents/skills/flatworld-pixel-art/assets/merchant-game-sprite-anchor.png`：仅用于角色类小尺寸可读性、像素簇和对齐参考，不作为统一画布或像素密度的硬约束。
4. `Assets/6_Art/Characters/Hana Caraka - Base Character sample/idle.png`：玩家的大头短身比例、点眼与底部 Pivot 参考。
5. `Assets/6_Art/Characters/Hana Caraka - Livestock & Fish [Sample]/Cow/Cow.png`：动物色块、浅色高光与紧凑轮廓参考。
6. `Assets/6_Art/Characters/MinifolksForestAnimals/Outline/MiniFox.png`：动物剪影、深色描边与高对比配色参考。

不要把第三方素材包中明显不同的写实、细线或高分辨率风格平均混入新素材。只选择最接近消费场景的参考。

## 工业方块风格锚点

用户认可的铁罐与钢罐是后续工业方块、金属设备的优先画风参考；绘图前实际打开以下 PNG，功能结构、视角和世界尺寸仍服从目标消费方：

- 铁罐：`Assets/6_Art/Generated/Chemistry/GasTankBlock_Iron/GasTankBlock_Iron_Idle.png`。
- 钢罐：`Assets/6_Art/Generated/Chemistry/GasTankBlock_Steel/GasTankBlock_Steel_Idle.png`。

沿用大块干净的金属面板、直线加固框、深色结构接缝和少量醒目的方形铆钉/角件。灰蓝金属为主，铁罐的橙色角件可作为少量强调色；不同材质用主色、框和角件区分，不靠堆叠装饰。允许锚点中的轻微大面明暗变化，保持轮廓和五金件的硬边像素块，避免油亮的 3D 高光、照片纹理、密集划痕和颗粒噪点；不为这类成图机械套用小型 Sprite 的 12–20 色限制。

满格连片方块采用平直正视的方形主体，填满一格，边框与角件服从实际切片区域，中央面板保持简洁；不添加突出画布的管道、底座、透视侧面或地面投影。其他设备保留必要的阀轮、表盘、格栅及自身轮廓，借用上述材质和细节密度；角色、动物、植被继续使用各自类别参考。

## 视觉语言

- 视角：2D 俯视角游戏可读的正面、背面或侧面视图；角色正面实际表现为轻微俯视的“朝下”方向。
- 轮廓：头部明显大于写实比例，身体短，四肢简化；主体缩小后仍能靠剪影识别。
- 描边：以同类别项目参考在相同世界尺度下的视觉粗细为准。低分辨率素材常见约 1 逻辑像素深炭色描边；更高像素密度素材可增加像素厚度来保持相同视觉重量，禁止变成细线插画。优先深棕、墨绿或炭黑，不使用均匀粗重的纯黑外框。
- 色块：采用硬边缘成组像素，不使用抗锯齿、模糊、照片噪点或高频抖动；工业金属面板按上方锚点保留轻微明暗变化，其他类别不使用渐变。
- 明暗：默认左上光源；主要材质使用中间色、阴影和最多一个高光，避免连续多级明度；工业面板按锚点控制变化幅度，不画成油亮立体渲染。
- 面部：1 像素点眼；眉毛、鼻子和嘴巴通常省略。表情依靠眼距、头发轮廓和姿势表达。
- 配件：保留能说明身份的 1-3 个大形状，例如商人的肩包、腰包和卷毯；删除无法在目标尺寸辨认的细节。

## 商人锚点调色板

以下颜色用于理解色相关系，不要求每个素材逐字复用：

- 轮廓与最深阴影：`#282611`、`#322D17`
- 头发与皮革：`#6A502B`、`#8E6733`
- 暖黄色服装：`#B98B33`、`#D3A03B`
- 肤色：`#D2B387`、`#F6D4A7`
- 中性布料：`#706A47`

颜色数量以最近的同类别项目参考为准；提高像素密度不代表可以无节制增加色阶。低分辨率小型 Sprite 通常使用 `12-20` 个可见颜色，复杂主体可适当增加，但仍应保持清晰、有限的色块层级。透明像素不计入颜色数。

## 画布与主体边界

- “画布尺寸”是 PNG 的宽高；运行时 Sprite 应根据消费方契约和最近的同类别现有素材选择合适画布，用户指定的成品图可保持原始尺寸。
- “像素密度”可以高于现有低分辨率素材，但提高密度后必须通过 PPU/尺度配置保持正确的世界尺寸，并继续匹配同类参考的视觉块面与画风。
- “主体边界”是 Alpha 非零像素包围盒，可以小于画布，不得与画布尺寸混为一谈。
- 角色、动物和世界实体将主体放在画布底部中心；透明留白用于统一 Pivot、动画基线和场景对齐。
- 输出运行时 Sprite 时保留消费方所需的基线、占地和帧布局；用户指定原图直用时，不得擅自紧裁或改变画布。

## 逻辑尺寸与构图

| 类别 | 建议主体尺寸 | 默认画布/帧 | Pivot | 说明 |
| --- | --- | --- | --- | --- |
| 小型人类 NPC | 跟随现有角色比例 | 参考现有角色帧或消费方契约 | 底部中心 | 保持角色画风、基线和世界尺度一致 |
| 动物/小怪 | 跟随同类动物/怪物的体型比例 | 参考同类 Sprite/动画帧，可使用更高像素密度 | 底部中心 | 保留物种剪影，不因高分辨率增加写实细节 |
| 物品/工具/世界图标 | 跟随同类物品的主体占比 | 参考同类现有图标/世界 Sprite | 中心或消费方要求 | 保持强轮廓、有限色组和同类材质表达 |
| 树木/植被 | 跟随现有树木/植被的世界尺寸 | 按同类素材、Tile/Prefab 契约确定 | 底部中心或消费方要求 | 高像素密度允许更多像素，但叶簇、树干、明暗块面必须与现有环境画风统一 |
| 大型道具/建筑 | 按角色比例、占地与碰撞确定 | 按同类素材与消费方契约确定 | 底部中心 | 先检查 Tile、Prefab、碰撞与世界尺度 |
| 高清设计源 | 不限制 | 单主体、充足留白 | 按接入位置确定 | 是否直接用于运行时由用户选择和消费方契约决定 |

这些是新素材默认值，不是覆盖现有 Animator、Tile 或 Prefab 契约的理由。接入已有系统前必须检查消费方尺寸。

## 透明度与边缘

- 简单不透明主体使用纯色 `#ff00ff` 或 `#00ff00` 色键生成，再本地移除。
- 色键背景必须完全平坦，无投影、渐变、地面、反射和光照变化。
- 新绘制的小型像素 Sprite 默认只保留 Alpha `0/255`，并清理残留色键与孤立透明孔洞；用户指定原图直用时保留其原有 Alpha。
- 烟雾、玻璃、火焰、软毛等确实需要半透明时，按素材类别单独制定规则，不套用硬 Alpha 限制。
- 满格地面和连片工业方块使用全幅不透明主体，不生成色键背景或透明角落；边缘接缝以消费方的连接/切片规则为准。

## 分类补充

- 角色/NPC：优先保持现有角色的大头短身、点眼、色块与实用装备语言；商人锚点只作为已确认的角色风格补充参考。
- 动物/怪物：保留物种剪影，不把人类服装和比例强加给动物；轮廓与色块语言仍需统一。
- 物品/工具：必须先看项目内最近的同类道具；允许比旧素材使用更高像素密度，但仍保持强轮廓、有限材质色组、硬边缘和同样的俯视/侧视表达，不添加底座或背景卡片。
- 树木/植被：必须参考项目已有树木、灌木、草丛等环境素材；统一树冠/叶簇的块面组织、树干宽度、描边、光源、饱和度和世界尺度。高分辨率不能演变成细碎叶片、软笔刷或写实纹理。
- 建筑/世界道具：匹配俯视角、Tile 尺寸、角色比例和占地；大图仍保持像素级硬边缘与现有场景的块面语言。
- UI 图标：可以提高对比度，但不得改成光滑矢量、拟物照片或与世界素材完全脱节的厚涂风格。

## 否决项

- 写实人体比例、五官刻画、细手指或布料照片纹理。
- 光滑 3D 渲染、矢量圆角、软笔刷、强烈连续渐变和明显抗锯齿；工业锚点的克制金属明暗不属于否决项。
- 统一纯黑粗边、过饱和霓虹色或每个像素都不同的噪点。
- 内置投影、背景场景、文字、水印、图标卡片边框或无关装饰；设备自身的加固框属于主体结构。
- 未核对消费方尺度与导入设置就擅自缩放、量化或修改源图 Alpha。

## 验收清单

- 1 倍大小时能识别类别与身份。
- 导出画布符合真实消费方契约；没有契约要求时保留用户指定的成品图尺寸，主体没有越界或被裁切。
- 与最近的同类别项目参考按相同世界尺度并排时，比例、视角、轮廓重量、像素簇、配色和材质表达协调；即使新素材像素密度更高，也不能显得像另一套美术。
- 轮廓连续，眼睛、脚底、手持物和身份配件在目标显示尺寸下仍可辨认。
- 光源、明暗层级、描边厚度和调色板在同一动画或变体间一致。
- 新绘制的独立轮廓小型 Sprite 透明角落为 0，普通不透明主体没有色键残边；满格地面与连片工业方块保持全幅不透明，拼接边缘没有露底孔洞；用户指定原图直用时保留原始透明度。
- Unity 使用 Point 后没有压缩色块、模糊边缘或 Pivot 漂移。
