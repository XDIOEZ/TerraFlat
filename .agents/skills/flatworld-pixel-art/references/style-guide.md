# FlatWorld 运行时像素美术风格指南

## 参考优先级

从高到低使用以下参考；冲突时服从更高优先级：

1. `.agents/skills/flatworld-pixel-art/assets/merchant-style-anchor.png`：用户确认满意的角色设计语言，用于理解角色比例、服装大形、配色关系与身份配件。
2. `.agents/skills/flatworld-pixel-art/assets/merchant-game-sprite-anchor.png`：固定 `16×16` 画布的运行时版本，约束最终像素密度、颜色数量、对齐方式和小尺寸可读性。
3. `Assets/6_Art/Characters/Hana Caraka - Base Character sample/idle.png`：玩家的大头短身比例、点眼与底部 Pivot 参考。
4. `Assets/6_Art/Characters/Hana Caraka - Livestock & Fish [Sample]/Cow/Cow.png`：动物色块、浅色高光与紧凑轮廓参考。
5. `Assets/6_Art/Characters/MinifolksForestAnimals/Outline/MiniFox.png`：动物剪影、深色描边与高对比配色参考。
6. 与目标同类别、且实际已在游戏中使用的项目素材。

不要把第三方素材包中明显不同的写实、细线或高分辨率风格平均混入新素材。只选择最接近消费场景的参考。

## 视觉语言

- 视角：2D 俯视角游戏可读的正面、背面或侧面视图；角色正面实际表现为轻微俯视的“朝下”方向。
- 轮廓：头部明显大于写实比例，身体短，四肢简化；主体缩小后仍能靠剪影识别。
- 描边：逻辑分辨率下约 1 像素深炭色描边。优先深棕、墨绿或炭黑，不使用均匀粗重的纯黑外框。
- 色块：采用硬边缘成组像素，不使用渐变、抗锯齿、模糊、照片噪点或高频抖动。
- 明暗：默认左上光源；主要材质使用中间色、阴影和最多一个高光，避免连续多级明度。
- 面部：1 像素点眼；眉毛、鼻子和嘴巴通常省略。表情依靠眼距、头发轮廓和姿势表达。
- 配件：保留能说明身份的 1-3 个大形状，例如商人的肩包、腰包和卷毯；删除无法在目标尺寸辨认的细节。

## 商人锚点调色板

以下颜色用于理解色相关系，不要求每个素材逐字复用：

- 轮廓与最深阴影：`#282611`、`#322D17`
- 头发与皮革：`#6A502B`、`#8E6733`
- 暖黄色服装：`#B98B33`、`#D3A03B`
- 肤色：`#D2B387`、`#F6D4A7`
- 中性布料：`#706A47`

单个小型 Sprite 通常使用 `12-20` 个可见颜色，复杂角色上限为 `24`。透明像素不计入颜色数。

## 画布与主体边界

- “画布尺寸”是 PNG 的宽高；标准小型运行时 Sprite 固定为 `16×16`。
- “主体边界”是 Alpha 非零像素包围盒，可以小于画布，不得与画布尺寸混为一谈。
- 角色、动物和世界实体将主体放在画布底部中心；透明留白用于统一 Pivot、动画基线和场景对齐。
- 生成高清设计源时可以紧裁主体用于缩放计算，但输出运行时 Sprite 时必须重新放回固定画布。

## 逻辑尺寸与构图

| 类别 | 建议主体尺寸 | 默认画布/帧 | Pivot | 说明 |
| --- | --- | --- | --- | --- |
| 小型人类 NPC | 通常约 `12-14 × 15-16` | 固定 `16×16` | 底部中心 | 主体不得超出画布 |
| 动物/小怪 | 主体不超过 `16×16` | 固定 `16×16` | 底部中心 | 更大体型必须由消费方规格授权 |
| 物品/世界图标 | 主体不超过 `16×16` | 固定 `16×16` | 中心 | 通常留 1-2 像素安全边距 |
| 大型道具/建筑 | 16 像素倍数 | 按占地与碰撞确定 | 底部中心 | 先检查 Tile 与占地规格 |
| 高清设计源 | 不限制 | 单主体、充足留白 | 不适用 | 仅作本流程的设计与生成参考 |

这些是新素材默认值，不是覆盖现有 Animator、Tile 或 Prefab 契约的理由。接入已有系统前必须检查消费方尺寸。

## 透明度与边缘

- 简单不透明主体使用纯色 `#ff00ff` 或 `#00ff00` 色键生成，再本地移除。
- 色键背景必须完全平坦，无投影、渐变、地面、反射和光照变化。
- 小型运行时 Sprite 只保留 Alpha `0/255`；不得出现半透明边缘、残留色键或孤立透明孔洞。
- 烟雾、玻璃、火焰、软毛等确实需要半透明时，按素材类别单独制定规则，不套用硬 Alpha 限制。

## 分类补充

- 角色/NPC：优先保持商人锚点的大头短身、点眼、暖色块与实用装备语言。
- 动物/怪物：保留物种剪影，不把人类服装和比例强加给动物；轮廓与色块语言仍需统一。
- 物品/工具：减少透视细节，使用强轮廓与 2-3 个材质色组；不添加底座或背景卡片。
- 建筑/世界道具：匹配俯视角、Tile 尺寸、角色比例和占地；大图仍保持像素级硬边缘。
- UI 图标：可以提高对比度，但不得改成光滑矢量、拟物照片或与世界素材完全脱节的厚涂风格。

## 否决项

- 写实人体比例、五官刻画、细手指或布料照片纹理。
- 光滑 3D 渲染、矢量圆角、软笔刷、渐变和明显抗锯齿。
- 统一纯黑粗边、过饱和霓虹色或每个像素都不同的噪点。
- 内置投影、背景场景、文字、水印、边框或无关装饰。
- 高清源图直接缩放进游戏而没有量化、硬 Alpha 和像素级检查。

## 验收清单

- 1 倍大小时能识别类别与身份。
- 标准小型 Sprite 的导出画布精确为 `16×16`，主体没有越界或被裁切。
- 与最近的项目参考以相同缩放倍率并排时，比例和像素密度协调。
- 轮廓连续，眼睛、脚底、手持物和身份配件没有在缩小时丢失。
- 光源、明暗层级、描边厚度和调色板在同一动画或变体间一致。
- 透明角落为 0，普通不透明 Sprite 没有半透明像素和色键残边。
- Unity 使用 Point 后没有压缩色块、模糊边缘或 Pivot 漂移。
