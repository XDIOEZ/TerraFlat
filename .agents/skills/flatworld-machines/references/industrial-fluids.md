# 工业气液 V1

- 气、液按类型独立连接。管、阀、过滤管、出口没有库存或免费容量；`FluidNetworkGraph` 只保正式端口有向边及按腔体缓存的液网连通成员。不能搜索绕过方向、关闭阀门、过滤或端口指定组分。
- 泵和消费者工作腔独立保存物质；`CombineAdjacent` 只让四邻同定义方块罐组合，共享库存和相加的固定容量，气液/铁钢不互拼。`CombinedFluidTankInventory` 按容量保存各格份额，拆回、断桥和迁移守恒；异种液体拒绝合并，排空后重新判定。气量用标准 L、液量用 L，不结算工业压差、压缩功、换热、蒸发冷凝或超压爆炸。
- 铁/钢液罐方块为 `LiquidTankBlock_Iron/Steel`，各800L（满格1000L扣200L壳体）、四向液体口、禁止自然补气；组合容量按成员相加，沿用通用储罐和建筑快照，标志为液滴，气罐标志为气流。
- `IndustrialFluidTransfer` 是共用原子数量转移。普通气体按真实混合比例，过滤只取指定组分原有份额，剩余留来源。单液冲突拒绝，不转换或丢料；整液网异种检查按 `(节点, 腔体)`，不误并独立副产物腔。
- 气泵把标准升换算为摩尔后，调用大气源前须先按 `AtmosphereService.MinimumMoles` 量化总请求，再拆分混合组分；否则末组分会扣出非量子余量并污染星球库存。
- `FluidInventory` 扣料/排气按精确十进制余量与原温度重算内能，原子配方共用扣料前温度；不以浮点大数相减或清零极小尾料维持状态。回归 `Space/fuel_reaction` 与 `Tools/Tests/ShipFuel`。
- `CollectFluidSupplyRoutes` 逆向取源，`CollectFluidDeliveryRoutes` 正向找接收设备；`GetFluidRouteFilter` 统一读取路径筛选与端口限制。`GetFluidRouteCharge` 将筛选后净量还原为输入混气流量，所有共享路径预算按该流量扣，防多目标放大过滤能力。
- 每步先释放上一轮运行预约、冻结全部真实来源及节点流量，再给引擎预约。空管只保轻量节点预算，不复制库存快照。引擎在动力分配前预约真实原料，实际负载结算才消耗；无负载不扣料。氢发动机必须有真实氢、氧。
- `FuelEngine` 通过 `combustion-engine` 策略组合通用流体引擎，只从液体口接收 `core:fuel_oil`；预约和结算前都检查所属环境助燃资格，缺油、缺氧、关阀及空载不扣油。燃油物品先在坩埚转为液体，再经容器/储罐接入；规则 `fuel_oil_engine_definition`、现场 `fuel_oil_engine`。
- 完整机器计算步内禁止重建拓扑，读管路、面板和快照的回调沿用本步图与预算；标脏在下一步冻结预算前消费。组合罐液体身份变化只标脏流体图，同一步多次入液合并分摊和成员通知，不改变物质转移时机。
- 气泵有动力、真实环境气源和接收容量才抽取；一次取得真实混气，未接收组分归还来源。水泵按10L整批：先沿当前目标路径消费本步流量额度，`WorldLiquidPumpLiters` 攒满10L才从地表扣1份并整批交付；未攒满不提前存物料，无动力/无源/不足10L空间/路径变化清额度，失败原子归还。共享水域仍先找大于1份的供水格并保留1份，搜索耗尽后才抽入口末份；扣量及归还使用真实供水位置。
- `NaturalFillFraction` 默认 .2，只限制自然补气目标，不排已有超量。动力泵可达到 `GasCapacityStandardLiters`。铁/钢便携罐沿同一固定容量规则，不因充满运行旧超压逻辑。
- 气/液装填设备各有三个真实容器槽，按0→1→2装，满槽或不适合槽可跳过；实际物品和权威库存走原有库存命令。液体通过 `ILiquidTransferPort` 装实际液体容器。
- 出口 `OutputLitersPerSecond` 支持0关闭，负初值使用定义默认速率。气体按组分比例排入所属环境；液体按 `(出口,物质)` 累积10L额度，单步可排多整份，通过正式地表接口接收；拒绝保留来源，部分接收退回余量。爆罐溢液同样每1份扣10L，不足10L保留队列。
- `PullFromNetwork` 用于供气器/培育器及船用化学引擎等消费者，从可达来源补充自己的工作腔；普通储罐不启用。外部船舱、呼吸、天气仍复用共用物质定义和热力学，工业不再调用那些求解器。
- 保存、联机、拆回只带各设备本地库存或组合罐的单格份额；客户端逐包合入权威份额，不重新分摊尚未收齐的总量。快照排除 `engine:` 运行预约。迁移先撤运行预约再整批交接；销毁仅释放本格份额，失败保留未完成部分。模板补给按各成员定义累加一次。
- 固定结构工业模板用 `gas.standardLiters` 与固定容量校验；`CabinGas` 继续原有气压初始化。线协议随序列化结构变化升版，不做旧存档兼容。
- 离线生产回归：`dotnet run --project Tools/Tests/IndustrialGasNetworks/IndustrialGasNetworks.Tests.csproj --configuration Release`。正式Lua按 IndustrialFluids 清单执行；离线不等于Unity玩法或真实双端验收。用户PlayMode时不刷新、暂停、退出或切场景。
