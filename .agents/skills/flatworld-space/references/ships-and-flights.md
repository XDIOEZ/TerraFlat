# 船体、推进、起降与乘员

## 装配与移交

- ShipGroundAssembly 点火时收集四邻地板和完整承载建筑，批量移交真实机器后 AddPiece/起飞；落地按船本地原点吸附最近格线，不用重心，成功后地面只剩普通建筑，无 ShipView/ParkedPieces。外部补给走正式端口/阀门，未加载地表延迟物化；落点冲突保留整船阻挡并报告。
- 落地先整组成员占地预检，再捕获最新库存/耐久/JSON。ShipGroundRestoreGate 以占地版本、成员身份/结构、世界、落点/姿态/重心和准备代际判重；输入不变不复制快照、不重抛，变化立即重试。
- SpaceSession.GroundPreparation 按本地格、结构修订、资源代际共享每帧 2ms 预算。候选建筑不激活/登记，机器只预建表现，真库存继续归船；受控下降最后 0.5 米用真实推力等待，失动力照常坠落。异常/超时记一次后回退正式恢复；最终格整组预检、最新状态批量移交/显示/去重刷新，取消或失效回收候选。
- 安装/落地统一 Mod_ShipPart.ResolveGroundOccupancyLayer：地板 6，其他优先正式机器层，否则显式部件层（光纤 5），不能回退普通建筑默认层。同格同层及地面真实占用仍拒绝，原因含格/层/部件。
- 四邻地板定义船体；接触、补地板、光纤不形成对接。独立船经墙接口和双方控制台确认连整体，断开清双方确认并重算连接，保留身份/库存/分离速度。ShipAssemblyCache 复用拓扑、逐步更新质量/运动，模拟和即时查询缓存分开；机器/库存以本船格子为域。

## 推进与导航

- WASD 累加平移推力，松键滑行、反向渐进制动；检查点火及真实动力，升空保留点火，无输入不耗油，无动力不清碰撞超速。Q/E 不出力/耗油/取消导航。
- ShipThrustAllocation 按速度变化选喷嘴（左推用右侧向外喷嘴），成员角度和安装 QuarterTurns 决定实际方向；同向引擎按容量同比供油，缺某侧只失该方向，不借其他喷嘴。
- 引擎本地 +Y 气相输入、-Y 喷口，严格一格。ShipEnginePlacement 共用预览/提交/可用引擎的外缘和净空检查，后建物也不能堵喷口；气密只读 SealsAtmosphere，边缘引擎可替墙。固定船型同时改引擎/墙/线并保留舱门至控制台前两格中央通道；地表 BodySizeCells=1，单改 rendererScale 无效。
- 每台从本船正式气相网取料，端口/阀门/选择器/逐段共享吞吐约束生效，不跨对接船扣罐。燃料是真实罐内近 2:1 氢氧气相，按 mol 原子扣量，不另造物质；固定船补给按成员和共享罐实际组容量分配。
- 整体只留最新导航任务，手动接管/到点结束。停机/断电/缺油保留任务和惯性，复电续航；制动同样耗真实燃料。光纤能力查实际连接。

## 起降与迁移

- Landed/Floating 不积动力或做船间动态碰撞，机器/舱气/自由乘员继续；起飞先同步载荷。Lifting 只改高度/竖速/燃料，物理坐标静态、表现升高。
- 只有 land/按钮写 RequestedLandingBodyId；范围含船半径及 max(100米,星体半径/4)。CommitSurfaceContacts 在物理后处理；有真实触地才租 ListPool 快照按接触时间排序，先清待处理字典，再提交，新增接触留下一步。
- 起飞完成需达到 TakeoffSpeedMetersPerSecond 且至少 12 秒，不看高度/星球半径；进入太空位于星体边缘外船半径+12米，只继承星体平移速度。降落约 10 秒，每步走真实引擎/电力/管路；断电缺油真坠落，可再点火，持续受控且触地竖速≤0.5米/秒才免冲击。
- 船下降自动接管本船控制台并关窗口，WASD 世界轴平移，船/镜头朝上、跟整船中心；同次 Esc 退出不强制重进，触地或返太空还镜头。平移/制动要真动力但独立于点火救船的垂直力，无输入/动力/驾驶员仍保留惯性。
- 末步先按 Fraction 处理船/乘员/散物接触，再以最终速度与真实船体落点中心决定陆海并提交，Floating 禁驾；船不能 UI 选点/随机跳点，独自玩家保留附近选址/随机落点。
- 冷地表只读冻结 Profile+最新差量；环境层、天气 Profile windStrength、正式河/海流采样不加载 Scene、不借玩家天气。
- TryTeleportPlayerToSpace 接所属区坐标/速度，处理脱支撑/驾驶/下落及失败恢复。地表↔太空走 DimensionManager 快照/加载页，普通跨区只调租约/Scene；读档按星区/阶段恢复，未就绪不下落。
- 太空死亡回主地球固定主世界出生点：SpaceSession.Respawn 在完整重生前解驾驶/支撑/下降，以中立乘员/transitionRunning 防重建太空归属，成功清记录、失败恢复；不把星区 Scene 写成出生点。

## 乘员

- 非驾驶失重 WASD 按屏幕轴，Mod_Mover.SmoothSpaceVelocity 无摩擦、反向渐刹。FreeWalkVelocity 仅主动分量、差量并入 FreeMotion；离船继承船点速度+步行，12米/秒只限主动分量。禁跑，WASD 不耗推进气体。
- 支撑/步行后以所属船 LocalX/LocalY 验地板，不用滞后视图；自由乘员再探新支撑，支撑毁坏即释放。地表用当地重力/ SmoothSurfaceVelocity；供电人工重力舱内直接步行并用地球重力，落地仍有效、不叠当地重力，密闭查询不请求地表环境。
- Mod_Mover.SetSpaceUpright 清本体/刚体角和角速度，保留 Mod_TurnBack 翻面/瞄准；关闭镜头跟转恢复绝对零角。驾驶/联机 BindConsoleControl 保留本船 LocalX/Y，首次/换船从当前位置换算，不吸附控制台中心。
