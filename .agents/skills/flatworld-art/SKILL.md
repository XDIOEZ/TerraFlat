# FlatWorld 绘图与美术

## 游戏主体画风

> 低饱和、偏写实的复古像素风，像素数量要稍低。

- 低饱和：以自然、克制的材质色为主，少量强调色承担识别；同一组素材保持统一的调色板与光源。
- 偏写实：用可信的结构、自然比例和材质关系表达对象；默认不套用夸张大头短身、点眼或二次元立绘模板。已确认的角色身份特征仍需保留。
- 复古像素：使用清楚的硬边像素簇、简洁轮廓和少量明暗层级，避免柔化、照片纹理、油亮 3D 高光及密集噪点。
- 像素数量稍低：优先较低的逻辑分辨率、较大的像素块与较少细节；具体画布由使用它的 Sprite、动画、Tile 或 UI 决定，不规定全项目统一尺寸，也不擅自缩小已有帧或改变 PPU。
- 这套方向适用于新绘和重绘的游戏素材，包括人物立绘与 UI 图标。用户本次明确指定其他画风时，按该素材的要求处理；仅要求大图或高清输出时，仍保留低逻辑分辨率的像素观感。旧参考中的高像素密度、Q 版或高清插画处理不自动成为新图默认值。

## 制作与交付边界

- 先打开最接近目标的同类素材，确认用途、视角、实际显示大小、画布/帧布局、透明度和接入位置。参考分别承担身份、结构、姿势或材质职责，不能覆盖上方主体画风。
- 位图生成与编辑遵循当前绘图工具的使用要求；需要透明背景时使用工具支持的透明输出。用户要求原图直用时保留原文件，不默认紧裁、量化或改 Alpha。
- 同一套动画或变体保持身份、比例、调色板、光源、像素块大小和对齐一致；每次迭代只改变本次要求的部分。
- 游戏素材输出到 `Assets/6_Art/Generated/<System>/<Name>/`，立绘使用 `Actors/<Name>/`；机制图按专用参考保存。只画图不自动扩展成玩法、Prefab、Animator 或 UI 代码修改。
- 汇报给出实际成品链接、用途与必要规格，区分素材生成、Unity 接入和用户观感验收。按用户要求决定验证范围，不把未执行的检查说成已通过。
