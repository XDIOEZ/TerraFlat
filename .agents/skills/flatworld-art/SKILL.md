# FlatWorld 绘图

## 默认画风

**角色、动物、物品/图标、工具、装备、建筑、地块及特效，默认采用低饱和的大色块、大像素块复古像素风。**

- 以[现版熊与玩家](references/art-direction.md#像素颗粒基准)为共同基准，按实际游戏显示大小对齐像素颗粒；类别参考提供身份、结构和材质，不覆盖本节画风。
- 自然比例、硬边轮廓、少量大块明暗；五官、毛发、木纹、金属反光都保持同一粗颗粒。避免初版熊那种密集碎纹理、碎色阶的“高清像素”，不以高清插画加像素滤镜替代。放大也不补细节。
- 用户明确指定其他画风时优先；旧素材仅细修时保留原设计，不自行批量重画。

## 绘制约定

- 先看同类实际素材和消费方；物品还要核对定义、配方、原料与科技阶段，结构和工艺符合用途。
- 重绘先实际传入原图，保留主体、身份与朝向，不擅自加容器或底座；旧素材细修保留设计、配色与正常细节，明确要求重画才改画风。
- 像素粗细看逻辑分辨率和实际显示大小。保留原图与 Alpha，不擅自缩图、全图限色、有损压缩或导入降采样；用 PPU/缩放控制游戏尺寸。
- 独立轮廓透明，满格 Tile 不透明；原图直用保留画布。仅绘图不顺带改玩法。
- 游戏图放 `Assets/6_Art/Generated/<System>/<Name>/`，立绘归 `Actors/<Name>/`。分类细节只维护在本 Skill 的参考中。
