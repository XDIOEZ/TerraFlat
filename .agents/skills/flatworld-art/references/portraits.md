# 人物立绘与身份

## 资产用途

| 类型 | 用途与构图 | 命名 |
| --- | --- | --- |
| Portrait | 对话、角色页或任务 UI；默认单人、自然平视、竖版全身 | `<Name>_Portrait_FullBody_<Expression>.png` |
| Concept | 探索设计，构图按确认目标决定，不承诺直接进入 UI | `<Name>_Concept.png` |
| Sprite | 场景运行时移动与动画，视角与帧布局由消费方决定 | `<Name>_<State>_<Direction>.png` |

三类资产可共享身份参考，但不能直接互相替代；Portrait 按 UI 重新构图，不把运行时 Sprite 放大后直接作为正式立绘，也不把立绘缩小后直接当作动画帧。

## 画风与身份

- 默认沿用主入口的低饱和、偏写实、较低逻辑分辨率的复古像素画风。立绘用途或大画布本身不代表切换高清二次元插画；用户本次明确要求其他表现方式时才针对该图切换。
- 同角色参考位于 `Assets/6_Art/Generated/Actors/` 及实际运行时素材。锁定年龄感、体型、发型、面部印象、服装结构、主配色、配件与职业气质；只补充能解释既有设计的必要结构。
- 输入图分别标注 `identity reference`、`art-style reference` 和 `pose reference`；画风或姿势参考不得复制、覆盖其他人物的身份。运行时俯视构图与帧规格不强加给立绘。
- 让职业、生活习惯决定站姿和细节，保留自然的不对称与少数身份焦点；避免模板俊美脸、英雄展示站姿、配件堆叠、随机划痕和均匀铺满的细节。用户反馈生成感强时先调整设计取舍，不继续堆精细度。
- 用户明确要求非像素平涂时，使用大面积固有色和一档硬边阴影；材质保持哑光、克制，不额外加入柔化、油亮皮肤、湿亮皮革或电影光效。

## 构图与交付

- 默认平视、自然站姿或轻度职业动作，人物居中，头脚、服装与身份配件完整，四周约 8%–12% 安全留白；实际构图服从用户与 UI。默认竖版可参考 3:4 或 2:3，未明确 UI 尺寸时不虚构像素契约。
- 输出透明 PNG，不添加场景、底座、边框、文字、水印、光环、地面或投影。像素轮廓保持干净硬边，半透明材质按实际需要处理；明确要求非像素插画时允许平滑 Alpha。
- 保存到 `Assets/6_Art/Generated/Actors/<Name>/`；保持同角色表情或动作变体的比例、配色、服装和像素尺度一致。
- 仅在要求接入 UI 时配置 Unity。像素立绘使用 Point、Alpha、关闭 Mipmap；大尺寸展示按整数倍或布局需要保留像素边缘。明确要求的非像素插画才使用平滑过滤；锚点、图集和 Addressables 由 UI 消费方决定，不套用世界 Sprite 的 PPU/Pivot。
