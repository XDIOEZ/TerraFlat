# 游戏素材画风与参考

主体画风以 [SKILL.md](../SKILL.md#游戏主体画风) 为准。旧图用于提供身份、结构、视角和世界尺度；不因沿用旧参考而恢复高像素密度或高清插画默认值。

## 参考职责

- 优先查看 `Assets/6_Art/Generated/<System>/` 中实际已使用的同类素材；同目录不足时再找其他目录的同类图。物品参考物品、动物参考动物，不用跨类别素材统一画布。
- 同角色参考决定年龄感、体型、发型、面部印象、服装、主配色与标志配件；画风参考只提供符合主体方向的表现方式，姿势参考只约束动作。
- `../assets/merchant-style-anchor.png` 与 `../assets/merchant-game-sprite-anchor.png` 保留商人身份、服装大形及小尺寸可读性的参考价值，不统一规定所有角色的比例或像素密度。
- 玩家换装参考 `Assets/6_Art/Generated/Characters/PlayerTemplate/`；动物侧向动画布局参考 `Assets/6_Art/Characters/MinifolksForestAnimals/Outline/MiniWolf.png`。这些参考的接入细节见 [runtime-sprites.md](runtime-sprites.md)。

## 像素与材质表达

- 用较少、成组的逻辑像素表现主体；在实际显示大小下先保证剪影、功能结构和身份能辨认，再决定必要细节。不靠提高分辨率、增加色阶或单像素噪点补充完成度。
- 默认左上光源；主要材质以中间色、一档阴影和必要的小面积高光区分。金属可有克制的大面明暗，避免连续柔和渐变、照片颗粒和密集划痕。
- 描边服从同类素材在相同世界尺度下的轮廓重量，优先深棕、墨绿或炭灰；不默认添加统一纯黑粗框。
- 小型 Sprite 常见约 12–20 个可见颜色，仅供预算参考，不是全类别硬上限；透明像素不计入。低饱和仍需保留材质色相、明暗和必要强调色的区别。
- PNG 画布、逻辑像素密度、主体 Alpha 包围盒和世界尺寸分别处理。放大交付用最近邻保留像素块；透明留白可能承担 Pivot、基线或帧布局，不自动紧裁。

## 类别差异

| 类别 | 保留重点 |
| --- | --- |
| 人物、动物与怪物 | 自然且可辨识的体型、物种剪影与少量身份配件；不把人类服装或商人比例套给动物 |
| 物品与工具 | 功能轮廓、握柄与主要材质；不添加背景卡片、底座或无法辨认的装饰 |
| 树木与植被 | 成组叶簇、树干宽度、光源与世界尺度；用块面归纳，不逐片堆叶或软笔刷纹理 |
| 建筑与世界道具 | 俯视/侧视关系、占地、碰撞与角色尺度；大体积仍保持克制的像素密度 |
| UI 图标与人物立绘 | 随显示区域调整构图与信息量，默认延续主体像素画风；身份与接入细节按对应参考 |

## 工业方块与设备锚点

铁罐、钢罐是工业金属设备的材质和结构参考，绘制前打开实际 PNG：

- `Assets/6_Art/Generated/Chemistry/GasTankBlock_Iron/GasTankBlock_Iron_Idle.png`
- `Assets/6_Art/Generated/Chemistry/GasTankBlock_Steel/GasTankBlock_Steel_Idle.png`

沿用灰蓝大面板、直线加固框、深色结构接缝与少量方形铆钉/角件，铁罐橙色角件可作小面积强调。用主色、框和角件区分材质，细节密度仍服从主体方向。

满格连片方块采用平直正视、全幅不透明的方形主体；边框与角件服从消费方切片，中央面板简洁连续，不添加透视侧面、突出管道、底座或地面投影。独立设备保留真实阀轮、表盘、格栅和自身轮廓，连接件另走运行时图层。
