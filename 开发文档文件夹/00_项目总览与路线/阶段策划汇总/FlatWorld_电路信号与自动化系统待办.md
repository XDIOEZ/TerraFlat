## 1. 实施目标与顺序

**第一阶段：设备工作状态 → 1 位信号线 → 状态显示。第二阶段：基础逻辑门 → 继电器 → 电力通断。第三阶段：有线与无线信号互通。**

```text
电子设备实际工作状态（0/1）
            ↓
          信号线 ───→ 状态显示
            ↓
         基础逻辑门
            ↓
      继电器信号输入
            ↓
       电力触点接通/断开
```

- **1 = 正在工作，0 = 没有工作**。这里的“工作”指设备正在产生实际功能，不等于仅仅已接通电源或开关处于开启状态。
- 例：电灯实际发光、泵实际输送、电动机实际输出动力时为 `1`；停机、缺电、没有实际工作时为 `0`。电池仅在实际充电或放电时为 `1`，有剩余电量但待机仍为 `0`。
- **设备直接输出状态**，信号线传递状态，逻辑门计算新信号，继电器根据状态切换电力触点。
- **信号线与电线各自独立**：电线传输电力（W/J），信号线传输固定 1 位的 `0/1`。

## 2. 基础信号规则（已实现，待现场验收）

### 2.1 直接接线与网络

- [ ] 在现有世界机器和电网架构上增加独立的 **1 位信号覆盖层**，相邻信号线连成信号网；支持放置、拆除、跨区块与世界作用域。
- [ ] 电子设备可声明信号**输出端口**，信号线直接读取设备状态；端口位置随设备朝向变化。
- [ ] 电力线与信号线可在同一位置交叉，各自保持独立连接；同层交叉的信号线连成一网。
- [ ] 同一信号网的多个设备采用 **OR 合并**：只要有一个设备输出 `1`，整网为 `1`；全部输出 `0` 或没有有效输出源时为 `0`。

### 2.2 工作状态来源

- [ ] 具有明确工作状态的设备声明输出端口，由业务模块通过统一只读接口提供 `正在工作`（布尔值）；信号网络直接读取接口结果。
- [ ] 工作状态由实际业务结算决定，不能仅凭“已启用”“接上电网”或“电池尚有储能”推断。
- [ ] 设备停止、失去供电、被拆除或端口失效后，相关信号及时更新为 `0`；不得保留上一次的 `1`。
- [ ] 设备运行状态结算后统一刷新受影响的信号网，沿用现有世界机器调度。

### 2.3 表现、保存与验收

- [ ] 查看设备端口或信号线时，能直接看到当前 `0/1`；电力线与信号线外观可区分。
- [ ] 信号线位置与网络连接随世界保存、休眠和恢复；当前 `0/1` 由设备实时工作状态重新计算。
- [ ] 验证：电灯亮/灭、泵运行/停止、机器缺电、设备拆除、同网两设备 OR 合并、跨区块与存档恢复。只在游戏内真正验收后勾选。

## 3. 基础逻辑门（已实现，待现场验收）

- [ ] 增加四种可放置逻辑门：**与门（AND）、或门（OR）、非门（NOT）、异或门（XOR）**，接入现有 1 位信号网。
- [ ] **与门 AND**：输入 A、B 都为 `1` 时输出 `1`，否则输出 `0`。
- [ ] **或门 OR**：输入 A、B 至少一个为 `1` 时输出 `1`，否则输出 `0`。
- [ ] **非门 NOT**：输入 A 为 `0` 时输出 `1`，输入为 `1` 时输出 `0`。
- [ ] **异或门 XOR**：输入 A、B 不同时输出 `1`，相同时输出 `0`。
- [ ] AND、OR、XOR 各有独立的 A/B 输入端和一个输出端；NOT 有一个输入端和一个输出端。端口随放置朝向旋转，输入与输出各自连接对应信号网。
- [ ] 未连接的输入按 `0` 读取；输出端作为所在信号网的一个信号源，沿用多源 OR 合并规则。
- [ ] 输入信号变化后由统一信号调度刷新门输出，反馈连接按确定顺序结算，避免无限重复计算。
- [ ] 保存逻辑门种类、位置与朝向；世界恢复后根据输入信号重新计算输出，支持跨区块连接。
- [ ] 交互时显示每个输入端与输出端的 `0/1`；验证四种逻辑门全部输入组合、断线、拆除、旋转、门级串联、反馈连接及存档恢复。

## 4. 继电器（已实现，待现场验收）

- [ ] 增加可放置的**继电器**，具有一个 **1 位信号输入端**和两个独立的**电力触点 A/B**；端口位置随放置朝向旋转。
- [ ] 继电器读取所接信号网的 `0/1`：**输入 `1` 时 A/B 接通，输入 `0` 时 A/B 断开**。
- [ ] 信号线脱离、信号源失效或信号网无有效输出时，继电器按 `0` 处理并断开触点。
- [ ] 电网拓扑根据触点状态增删 A/B 之间的电力连接，复用现有电压兼容、发电、负载和储能结算。
- [ ] 电网结算设备工作状态 → 刷新信号网 → 更新继电器触点 → 下一轮电网结算按新拓扑运行；每轮按确定顺序提交，保证反馈回路的结果稳定可复现。
- [ ] 放置、拆除、旋转、跨区块与世界恢复时刷新两侧电力连接；保存继电器位置与朝向，触点状态由信号重算。
- [ ] 继电器交互显示**输入 `0/1`**、**触点接通/断开**以及两侧电力连接状态。
- [ ] 验证：`0/1` 切换供电、信号源失效、信号线断开、继电器拆除、旋转端口、串并联、多电源、跨区块与存档恢复。

## 5. 无线电信号转换（已实现，待现场验收）

- [ ] **无线电信号转换器（有线↔无线）**：在 [无线电系统规划 §3](../../06_交通建筑与交互/无线电系统规划.md) 的电路联动阶段，同一设备可选**发射**（读取有线网 `0/1` 并发往所调频道）或**接收**（把同频道有效无线 `0/1` 作为有线网的一个输出源）。
- [ ] 频率复用无线电**整数频道 ID**，不同频道隔离；多个有效同频道来源按 OR 合并。接收端区分**有效的 `0`**与**断电/失联/超时**，失去有效来源时回 `0`；检测并拒绝同一信号网内的收发回环。

---

**实施原则：** 先完成 1 位信号网，再接入基础逻辑门和继电器，最后接入无线转换；复用设备真实工作状态、现有电力网络与世界机器调度。

## 6. 本轮实现与验收记录

- `CircuitSignalNetworkGraph` 提供独立第4层、旋转端口和多源OR；真实工作态由设备业务提供，线路不创建逐线逻辑或逐线更新。
- 四门读取上一固定步输入，统一提交结果；反相环按步确定性振荡。继电器双触点只改变下一轮电力拓扑，不重建无关机械/流体网络；主体格拒绝电线穿越。

- 线路与设备端口显示0/1，客户端按修订号接收轻量位值/供电变化；派生信号、接点及无线在线来源不持久化。
