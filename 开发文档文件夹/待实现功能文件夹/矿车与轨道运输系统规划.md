# FlatWorld 矿车与轨道运输系统规划

## 1. 定位
用于矿区、基地、工厂之间运输玩家和物品。参考 Minecraft 矿车，同时复用项目木筏的载人方式。

## 2. 轨道
轨道是唯一需要制作的运输设施。

- 铁轨：提供矿车移动路径。
- 动力轨：后续提供加速能力。

轨道按世界格保存，不创建逐格 GameObject。

## 3. 矿车
矿车是可连接的移动载体，移动逻辑参考项目木筏。

矿车之间通过前后连接点连接：

```text
动力矿车 - 货物矿车 - 货物矿车 - 载人矿车
```

连接后生成矿车组（MinecartGroup），所有矿车作为整体移动。

矿车组保存：

- 矿车列表
- 当前速度
- 移动方向
- 推动力
- 阻力

矿车组采用木筏同款推动逻辑：

动力来源产生推动力 → 作用整个矿车组 → 矿车组统一移动。

不计算每节矿车独立动力，不模拟复杂铁路调度。

类型：

- 无动力矿车：依靠惯性、坡度和动力轨移动。
- 动力矿车：可安装动力模块。

矿车连接规则：

- 矿车靠近连接点自动吸附。
- 前后方向均可连接。
- 连接后形成整体运输组。
- 断开连接后矿车组分离。

动力模块：

- 内燃机
- 蒸汽机
- 后续其它动力来源

动力矿车只是动力载体，动力模块负责：

- 提供推动力。
- 消耗燃料。
- 控制启停。

矿车负责连接、移动和载荷。

## 4. 载荷

- 载人矿车：参考木筏，实现玩家进入、乘坐、离开。
- 货物矿车：参考箱子，拥有独立库存，可运输物品。

### 载人矿车

参考木筏实现：

- 玩家进入矿车。
- 摄像机跟随矿车移动。
- 离开矿车后恢复玩家控制。

### 货物矿车

参考箱子实现：

- 拥有独立库存。
- 玩家可以打开并取放物品。
- 后续支持自动装卸。

## 7. 移动规则

矿车只沿轨道连接方向移动，不使用 A* 或铁路信号系统。

- 普通矿车保留惯性。
- 下坡可滑行，上坡减速。
- 动力矿车推动整个连接矿车组。
