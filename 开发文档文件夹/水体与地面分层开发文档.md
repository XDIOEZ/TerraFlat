# 水体与地面分层开发文档

状态：待实现

## 目标

```text
GroundTileId    = 真实固体地面
WaterDepth      = 当前水深 0~1
LiquidTypeIndex = 运行时液体索引
LiquidId        = 稳定液体 ID
```

原则：

> Ground 只管地，WaterDepth 只管水量，LiquidId 只管是什么水。

抽水只能减少 WaterDepth，禁止抽水时生成湖底 / 海底。

## 规则

- 不创建新的 LiquidDepth。
- 继续复用现有 WaterDepth，Buff、体温、游泳、BRG、Navigation、AIECS 都读它。
- height / riverDepth 只负责生成初始 WaterDepth，运行时不能重新覆盖。
- 水域也必须提前生成真实 Ground。
- GroundTileId 不再保存 Water。
- 水体配置统一进入 `Assets/StreamingAssets/GameConfig/Liquids/liquids.json`。
- 运行时格子保存 LiquidTypeIndex，存档 / MOD 使用稳定 LiquidId。

示例：

```text
海洋：Stone + core:sea_water + WaterDepth
湖河：Clay/Gravel/Stone + core:dirty_water + WaterDepth
```

## Liquid JSON

液体可增加可选世界水体配置：

```json
"worldWater": {
  "spriteAddress": "...",
  "materialAddress": "...",
  "navigationCost": 20000,
  "shallowMoveSpeedMultiplier": 0.5,
  "deepMoveSpeedMultiplier": 0.2,
  "entryTemperatureFloor": 10.0
}
```

Sprite / Material / Shader 仍是 Unity 资源，JSON 只保存配置与资源地址。

## 最终数据

```text
ChunkTerrainData
├─ TerrainCell[] -> GroundTileId
├─ WaterDepth[]
├─ LiquidTypeIndex[]
├─ height
└─ riverFlow / riverKind
```

`TerrainCell.Flags.Water` 若暂时保留，只能作为兼容缓存。

## 实施顺序

### P0 水层
- [ ] ChunkTerrainData 增加 WaterDepth / LiquidTypeIndex。
- [ ] 海洋、河流、湖泊、地下水统一生成初始 WaterDepth。
- [ ] GroundTileId 不再保存 Water。

### P1 BRG
- [ ] Ground BRG 只读 GroundTileId。
- [ ] Water BRG 读取 LiquidDefinition + WaterDepth。
- [ ] 岸线改为 WaterDepth > 0。
- [ ] 保留现有四角水深插值。

### P2 玩法
- [ ] Buff / 体温 / 游泳继续使用 WaterDepth。
- [ ] Navigation / FlowField / AIECS 继续使用 WaterDepth。
- [ ] 喝水 / 抽水通过 LiquidId 读取 LiquidDefinition。
- [ ] Tile_Water 逻辑迁到普通 Water Runtime。

### P3 存档
- [ ] 保存 WaterDepth + LiquidId 稀疏差量。
- [ ] 未修改水格继续使用生成基线。
- [ ] 水体恢复早于渲染和导航绑定。

### P4 删除旧 Water Tile
- [ ] 迁移海洋 Biome。
- [ ] 迁移 MapCore 河流配置。
- [ ] 迁移 ChunkTilePalette_Default。
- [ ] 迁移地面 / Legacy Map Prefab。
- [ ] 无引用后删除 Tile_Water_Fresh / Tile_Water_Salt。
- [ ] 无用途后删除 Water TileBase。

### P5 抽水机
- [ ] 抽水只修改 WaterDepth。
- [ ] WaterDepth = 0 时 Water BRG 消失。
- [ ] 原 Ground 直接露出。
- [ ] GroundTileId 不允许改变。

## 验收

- [ ] 水下始终存在真实 Ground。
- [ ] 抽水前后 GroundTileId 不变。
- [ ] WaterDepth = 0 后正确露底。
- [ ] Renderer / Buff / 体温 / Navigation / AIECS 使用同一 WaterDepth。
- [ ] 淡水 / 海水仍正确区分。
- [ ] 保存、Chunk 重载后抽水结果不丢失。
- [ ] 无新增 Error / Warning。

```text
beforeGround == afterPumpGround
worldWaterDepth == buffInputDepth
worldWaterDepth == navigationPublishedDepth
```

## 本阶段不做
