# TerraFlat 世界生成三级参数设计

## 1. 系统定位

本文档用于统一 TerraFlat 世界生成、静态气候、水文、群系和动态环境的参数层级。

三级关系固定为：

- **1级 = 原始世界常量**：创建世界时确定的原始输入和固定配置。
- **2级 = 静态世界派生场**：根据1级生成，并允许2级数据之间按固定顺序继续计算。
- **3级 = 最终环境 / 生态状态**：消费1级和2级结果，形成最终世界环境与生态；本级允许存在动态变化。

本文档描述的是目标分层。当前项目已有实现不一定已经完全符合该结构，后续重构时以此文档作为依赖方向约束。

---

## 2. 分级规则

| 等级 | 定义 | 生命周期 | 是否允许被下级反向影响 |
| --- | --- | --- | --- |
| **1级：原始世界常量** | 世界创建时确定的原始输入、物理基准和固定生成配置 | 创建世界后固定 | **不允许** |
| **2级：静态世界派生场** | 根据1级生成；2级之间可以按固定顺序继续派生高度、温度、风、水汽、降水、水文等数据场 | 固定，可按相同输入重新计算 | **不允许** |
| **3级：最终环境 / 生态状态** | 消费1级和2级结果形成最终环境、群系、生态和运行时状态 | 部分固定，部分允许动态变化 | 只能改变3级状态，不能回写1/2级 |

2级内部允许存在明确的固定计算顺序。例如“高度 → 海陆 → 温度差 → 盛行风 → 水汽输送 → 静态降水”都属于静态世界派生过程，不需要为了每一步继续增加第4、第5级。

---

## 3. 1级参数：原始世界常量

1级参数必须尽量少。它们表达“创建这个世界时固定了什么”，包括原始物理常量和固定生成配置，而不是某个坐标最终计算出的环境结果。

| 1级参数 | 作用 | 备注 |
| --- | --- | --- |
| **WorldSeed（世界种子）** | 所有确定性随机的根 | 相同世界参数与算法下应得到相同结果 |
| **Topology（世界拓扑）** | 定义 Infinite / Wrapped 等世界拓扑 | 决定坐标归一化、环绕距离和纬度表达方式 |
| **WorldSize（世界尺寸）** | 定义有限世界尺寸或星球尺度 | Wrapped 世界用于纬度、极区和环绕范围 |
| **CoordinateScale（坐标尺度）** | 世界级坐标尺度 | 控制大陆、山脉、气候区等宏观尺度 |
| **HeightProfile（高度生成配置）** | 高度场生成规则 | 只描述生成规则，不代表某格实际高度 |
| **SeaLevel（海平面）** | 海平面基准 | 与高度场共同决定天然海陆分布 |
| **PlanetTemperatureBaseline（星球温度基准）** | 星球整体冷热基准 | 建议作为固定世界基准，不与运行时天气温差混用 |
| **StellarIrradiance（恒星辐照强度）** | 恒星对星球的基础辐照强度 | 用于产生全球受热差异；当前项目尚未形成完整独立参数 |
| **AxialTilt（轴倾角）** | 星球自转轴倾角 | 决定季节性受热变化；若首版不模拟可固定为默认值 |
| **Rotation（自转参数）** | 自转方向与速度基准 | 用于大尺度环流方向修正；若首版简化可固定为默认值 |
| **AtmosphereProfile（大气配置）** | 大气基础响应规则 | 描述受热差如何转化为环流、水汽承载等；不直接保存某地风向 |
| **OceanMoistureCapacity（海洋水汽供给能力）** | 海洋可向大气提供的整体水汽基准 | 控制世界整体偏干或偏湿 |

### 1级禁止项

以下内容不是1级参数：

- 某个位置的实际高度。
- 某个位置的温度。
- 盛行风方向。
- 降水量。
- 湿度。
- 河流、湖泊。
- 群系。
- 草、森林、动物和矿物分布。
- 天气状态。

这些都必须从原始世界常量继续派生。

## 4. 2级参数：静态世界派生场

2级表达“由1级常量确定出来的静态世界数据场”。同一组1级参数、算法版本和世界坐标必须得到相同结果。

2级数据之间允许互相按**固定的单向顺序**继续计算，例如高度先决定海陆，海陆与受热再参与温度和风，风再参与水汽与降水。这里的“互相计算”不允许形成循环依赖。

| 2级参数 / 数据场 | 主要来源 | 是否固定 | 作用 |
| --- | --- | --- | --- |
| **Height** 高度场 | Seed + CoordinateScale + HeightProfile | 是 | 山地、平原、盆地、海拔基础 |
| **Latitude** 纬度 | Topology + WorldSize + 世界坐标 | 是 | 全球受热梯度和大尺度环流基础 |
| **MeanSolarHeating** 平均恒星受热 | Latitude + StellarIrradiance + AxialTilt | 是 | 建立赤道到极地的长期平均热量差 |
| **Land / Ocean** 海陆分布 | Height + SeaLevel | 是 | 水汽来源、海洋性/大陆性和水文边界 |
| **Slope / Relief** 坡度与地形起伏 | Height 邻域 | 是 | 地表汇流、山脉阻挡和局地风修正 |
| **DistanceToOcean** 距海距离 | Land / Ocean | 是 | 海洋性/大陆性和水汽衰减参考 |
| **BaseTemperature** 地理基础温度 | PlanetTemperatureBaseline + MeanSolarHeating + Height + 海陆关系 | 是 | 静态温度主干，不由群系反向决定 |
| **PrevailingWind** 基础盛行风 | MeanSolarHeating + 全球温差 + Rotation + AtmosphereProfile | 是 | 全球大尺度空气输送方向 |
| **RegionalWindField** 静态区域风场 | PrevailingWind + Height + Slope + Land/Ocean + 静态温差 | 是 | 山地、海陆对风的固定修正 |
| **MoistureTransport** 水汽输送场 | RegionalWindField + OceanMoistureCapacity + Land/Ocean | 是 | 描述水汽从海洋向陆地搬运与损失 |
| **StaticPrecipitation** 静态降水 | MoistureTransport + Height + Slope + RegionalWindField | 是 | 迎风降水、背风雨影及长期干湿格局 |
| **DrainageDirection** 地表汇流方向 | Height + Slope | 是 | 决定天然径流向哪里流 |
| **Watershed / Accumulation** 流域与汇水量 | DrainageDirection + StaticPrecipitation | 是 | 决定河道规模、湖泊和洪泛区基础 |

### 2级内部推荐计算顺序

```text
1级原始世界常量
    ↓
Height + Latitude
    ↓
Land / Ocean + MeanSolarHeating
    ↓
BaseTemperature
    ↓
PrevailingWind
    ↓
RegionalWindField
    ↓
MoistureTransport
    ↓
StaticPrecipitation
    ↓
Drainage / Watershed
```

### 风的层级约束

- **风的物理/算法规则**可以属于1级 `AtmosphereProfile`。
- **基础盛行风**是根据恒星长期受热差、自转等计算出来的结果，因此属于2级。
- **地形和海陆修正后的区域风场**仍是静态派生结果，也属于2级。
- 当前天气造成的阵风、风力增强或短时风向偏移属于3级运行态。
- 不能直接用固定随机风向替代长期的受热与大尺度环流关系，随机量最多用于小尺度扰动。

## 5. 3级参数：最终环境 / 生态状态

3级承接1/2级结果，代表玩家和生态系统最终消费的世界状态。本级允许动态变化，但并不要求所有数据都变化：天然河流、初始群系等可以保持固定，天气、积雪、土壤湿度、动物生态等可以随运行时变化。

| 3级参数 / 状态 | 主要来源 | 是否变化 | 作用 |
| --- | --- | --- | --- |
| **River / Lake** 天然河流与湖泊 | Watershed + Height + StaticPrecipitation | 天然基线固定 | 决定河道、湖泊和洪泛区 |
| **GeographicTemperature** 最终地理温度 | BaseTemperature + 小尺度区域扰动 + 地形/静态气候修正 | 固定 | 群系、天然雪冰、生态基础 |
| **SoilMoisture / SurfaceMoisture** 土壤与地表湿度 | StaticPrecipitation + Height + River/Lake + 地表状态 | 可变化 | 植物、农业、泥地和局部生态 |
| **Biome** 群系 | GeographicTemperature + StaticPrecipitation + Moisture + Height + 水文 | 天然基线固定 | 沙漠、森林、草原、雪原等分类结果 |
| **NaturalSnow / Ice** 天然雪冰 | GeographicTemperature + 天然水体 | 天然基线固定 | 初始雪层、冻河、冻湖 |
| **VegetationBaseline** 天然植物分布 | Biome + 温度 + 水分 + Height + 水文 | 初始固定 | 草、森林、灌木、天然作物等初始生态 |
| **AnimalEcology** 动物生态 | Biome + 植被 + 生态规则 | 会变化 | 动物出生、死亡、迁移等 |
| **NaturalResources** 天然资源 | Height + Biome + 水文 + 资源规则 | 初始固定，可被开采 | 地表资源、矿物等 |
| **SeasonalTemperatureOffset** 季节温差 | AxialTilt + 日历/季节进度 | 会变化 | 叠加到当前环境温度 |
| **Weather** 天气状态 | 静态气候 + 世界时间 + 天气系统 | 会变化 | 降雨、降雪、雾、天气温差等 |
| **RuntimeWind** 当前风 | RegionalWindField + Weather + 季节/事件 | 会变化 | 当前风力、阵风、表现与玩法 |
| **SeasonalSnow** 季节积雪 | GeographicTemperature + 季节 + Weather | 会变化 | 降雪、积雪和融化 |
| **RuntimeTemperature** 当前环境温度 | GeographicTemperature + 星球运行时偏移 + 季节 + Weather + 局部热源 | 会变化 | 玩家、生物、物质的实际环境温度 |
| **LocalEnvironment** 局部环境 | 1/2级基线 + 液体 + 建筑 + 火源 + 玩家行为 | 会变化 | 局部热量、污染、水分等最终玩法状态 |

### 3级固定与动态的边界

3级不是“全部都会变化”。应区分两种数据：

1. **天然基线结果**：河流、天然湖泊、天然群系、初始植被、天然资源等，世界首次生成后作为确定性基线。
2. **运行时状态**：天气、季节温差、当前风、积雪、土壤含水量、局部冷热源、污染、生态数量等，可以随着时间和玩法变化。

运行时状态可以覆盖或改变玩家看到的世界，但不得反向修改1级原始世界常量和2级静态世界派生场。

## 6. 总依赖关系

```text
┌────────────────────────────────────────────┐
│ 1级：原始世界常量                          │
│ Seed / Topology / WorldSize                │
│ CoordinateScale / HeightProfile / SeaLevel │
│ PlanetTemperatureBaseline                  │
│ StellarIrradiance / AxialTilt / Rotation   │
│ AtmosphereProfile / OceanMoistureCapacity  │
└───────────────────┬────────────────────────┘
                    ↓
┌────────────────────────────────────────────┐
│ 2级：静态世界派生场                        │
│ Height / Latitude / MeanSolarHeating       │
│ Land-Ocean / BaseTemperature               │
│ PrevailingWind / RegionalWindField         │
│ MoistureTransport / StaticPrecipitation    │
│ Drainage / Watershed                       │
└───────────────────┬────────────────────────┘
                    ↓
┌────────────────────────────────────────────┐
│ 3级：最终环境 / 生态状态                   │
│ River / Lake / Biome / NaturalSnow         │
│ Vegetation / Animals / Resources           │
│ Weather / RuntimeWind / SeasonalSnow       │
│ RuntimeTemperature / LocalEnvironment      │
└────────────────────────────────────────────┘
```

禁止形成以下反向依赖：

```text
沙漠 → 降低降水 → 更加沙漠
森林 → 增加基础降水 → 更容易成为森林
雪原 → 强制基础温度变低 → 更容易成为雪原
天气 → 修改静态气候基线
玩家火炉 → 修改世界生成温度
```

正确方向应始终是：

```text
原始世界常量
  ↓
静态世界派生场
  ↓
最终环境 / 生态状态
```

## 7. 与当前 TerraFlat 的对应关系

| 当前概念 | 目标层级 | 处理方向 |
| --- | --- | --- |
| `WorldSeed` | 1级 | 保持 |
| `TopologyMode / Radius / ChunkSize` | 1级 | 保持，明确其世界拓扑职责 |
| `world.coordinateScale` | 1级 | 保持 |
| `terrain.height.*` | 1级规则 | 保持；实际 `height` 属于2级 |
| `terrain.seaLevel` | 1级 | 保持 |
| `PlanetData.GlobalTemperature` | 当前职责混合 | 后续应区分固定星球温度基准与运行时温度偏移 |
| `climate.equator.* / climate.polarBand.*` | 当前接近1级规则 | 后续可收敛到恒星受热/纬度温度模型 |
| `climate.wind.*` | 当前主要是生成规则 | 规则可留1级，实际盛行风和区域风必须作为2级结果 |
| `climate.temperature.*` 噪声 | 2级局部扰动 | 只能做少量区域温差，不能决定热带/寒带主结构 |
| `climate.precipitation.*` 噪声 | 2级局部扰动 | 后续应从降水主体降级为小尺度扰动 |
| `climate.orographic.*` | 2级静态气候规则 | 保持，接入正式水汽输送链 |
| `temperature.celsius` | 2级/3级边界 | 生成地理温度应固定；季节、天气、局部热源不得写回该基线 |
| `biome.*` 阈值 | 3级分类规则 | 只能消费气候和地形结果，不能反向生成气候 |
| `WeatherMgr` | 3级运行态 | 只叠加当前天气影响 |
| `SeasonalSnow` | 3级运行态 | 保持动态覆盖，不修改天然地理基线 |

## 8. 后续待规划

- `StellarIrradiance`、`AxialTilt`、`Rotation` 是否在首版暴露为玩家可配置世界参数，还是先使用固定默认值。
- Infinite 世界没有完整星球纬度时，如何定义长期受热梯度和基础盛行风。
- 2级静态区域风场首版需要模拟到什么程度，是否只做大尺度环流 + 山脉偏折，不实现复杂流体模拟。
- 海洋性/大陆性温差是否首版就使用 `DistanceToOcean`，以及具体影响范围。
- `PlanetData.GlobalTemperature` 后续拆分为固定星球基准与运行时调温时的最终字段命名。
- 静态水汽输送与降水算法确定后，再决定现有 `climate.precipitation.*` 噪声参数保留多少。
