# TerraFlat 世界生成三级参数设计

## 1. 系统定位

本文档用于统一 TerraFlat 世界生成、静态气候、水文、群系和动态环境的参数层级。

三级关系固定为：

- **1级 = 原始世界常量**：创建世界时确定的原始输入和固定配置。
- **2级 = 静态世界派生场**：根据1级生成，并允许2级数据之间按固定顺序继续计算。
- **3级 = 最终环境 / 生态状态**：消费1级和2级结果，形成最终世界环境与生态；本级允许存在动态变化。

本文档只记录当前项目已经存在、并且能在代码或配置中找到实际消费链的数据。尚未实现的气候物理概念不提前列入参数表。

---

## 2. 分级规则

| 等级 | 定义 | 生命周期 | 是否允许被下级反向影响 |
| --- | --- | --- | --- |
| **1级：原始世界常量** | 世界创建时确定的原始输入、物理基准和固定生成配置 | 创建世界后固定 | **不允许** |
| **2级：静态世界派生场** | 根据1级生成；2级之间可以按固定顺序继续派生高度、温度、风、降水、水文等数据场 | 固定，可按相同输入重新计算 | **不允许** |
| **3级：最终环境 / 生态状态** | 消费1级和2级结果形成最终环境、群系、生态和运行时状态 | 部分固定，部分允许动态变化 | 只能改变3级状态，不能回写1/2级 |

2级内部允许存在明确的固定计算顺序。例如“高度 → 海陆”“纬度温度 + 海拔/降水修正 → 地理温度”“固定种子静态风场 + 地形 → 静态降水 → 水文”都属于静态世界派生过程，不需要为了每一步继续增加第4、第5级。

---

## 3. 1级参数：原始世界常量

1级参数必须尽量少。它们表达“创建这个世界时固定了什么”，包括原始物理常量和固定生成配置，而不是某个坐标最终计算出的环境结果。

| 1级参数 | 作用 | 备注 |
| --- | --- | --- |
| **WorldSeed（世界种子）** | 所有确定性随机的根 | 相同世界参数与算法下应得到相同结果 |
| **Topology（世界拓扑）** | 定义 Infinite / Wrapped 等世界拓扑 | 决定坐标归一化、环绕距离和纬度表达方式 |
| **WorldSize（世界尺寸）** | 定义有限世界尺寸或星球尺度 | Wrapped 世界用于纬度、极区和环绕范围 |
| **CoordinateScale（坐标尺度）** | 世界级坐标尺度 | 控制大陆、山脉、气候区等宏观尺度 |
| **HeightProfile（高度生成配置）** | 高度场生成规则 | 只描述生成规则，不代表某格实际高度 |
| **SeaLevel（海平面）** | 海平面基准 | 与高度场共同决定天然海陆分布 |
| **PlanetTemperatureBaseline（星球温度基准）** | 星球整体冷热基准 | 当前由 `PlanetData.GlobalTemperature` 表达，并以默认 26℃ 的差值叠加到运行时环境温度 |

### 1级禁止项

以下内容不是1级参数：

- 某个位置的实际高度。
- 某个位置的温度。
- 盛行风方向。
- 降水量。
- 湿度。
- 河流、湖泊。
- 群系。
- 草、森林、动物和矿物分布。
- 天气状态。

这些都必须从原始世界常量继续派生。

---

## 4. 2级参数：静态世界派生场

2级表达“由1级常量确定出来的静态世界数据场”。同一组1级参数、算法版本和世界坐标必须得到相同结果。

2级数据之间允许互相按**固定的单向顺序**继续计算。当前实现中，高度决定海陆和地形修正；环世界纬度温度规则负责大尺度冷热；静态风场由固定种子生成，再参与迎风增雨和背风雨影。这里的“互相计算”不允许形成循环依赖。

| 2级参数 / 数据场 | 主要来源 | 是否固定 | 作用 |
| --- | --- | --- | --- |
| **Height** 高度场 | Seed + CoordinateScale + HeightProfile | 是 | 山地、平原、盆地、海拔基础 |
| **Latitude** 纬度 | Topology + WorldSize + 世界坐标 | 是 | 全球受热梯度和大尺度环流基础 |
| **Land / Ocean** 海陆分布 | Height + SeaLevel | 是 | 水汽来源、海洋性/大陆性和水文边界 |
| **BaseTemperature** 地理基础温度 | Wrapped：纬度 + 赤道/极圈配置 + 区域温度扰动；Infinite：温度噪声 | 是 | 静态温度主干，再叠加海拔、降雨和迎背风温差修正 |
| **StaticWindField** 静态风场 | WorldSeed + `climate.wind.regionSize` + `climate.wind.seedSalt` | 是 | 固定种子生成并平滑插值的区域单位风向 |
| **StaticPrecipitation** 静态降水 | 降水噪声 + StaticWindField + Height + `climate.orographic.*` | 是 | 基础降水叠加迎风增雨与背风雨影 |
| **DrainageDirection** 地表汇流方向 | Height + Slope | 是 | 决定天然径流向哪里流 |
| **Watershed / Accumulation** 流域与汇水量 | DrainageDirection + StaticPrecipitation | 是 | 决定河道规模、湖泊和洪泛区基础 |

### 2级内部推荐计算顺序

```text
1级原始世界常量
    ↓
Height + Latitude
    ↓
Land / Ocean + BaseTemperature
    ↓
StaticWindField
    ↓
StaticPrecipitation
    ↓
Drainage / Watershed
```

### 风的层级约束

- 当前世界生成没有恒星受热、自转或大气环流模型。
- 当前 `StaticWindField` 由 WorldSeed、`climate.wind.regionSize` 和 `climate.wind.seedSalt` 生成固定区域风向，再平滑插值为单位向量。
- 地形不会重新计算风向，只沿该静态风向采样逆风高度，用于迎风增雨和背风雨影。
- `PlanetData.WindStrength` 是3级运行时全局风力，主要控制当前天气/表现强度，不会改写2级静态风向。

## 5. 3级参数：最终环境 / 生态状态

3级承接1/2级结果，代表玩家和生态系统最终消费的世界状态。本级允许动态变化，但并不要求所有数据都变化：天然河流、初始群系等可以保持固定，天气、积雪、土壤湿度、动物生态等可以随运行时变化。

| 3级参数 / 状态 | 主要来源 | 是否变化 | 作用 |
| --- | --- | --- | --- |
| **River / Lake** 天然河流与湖泊 | Watershed + Height + StaticPrecipitation | 天然基线固定 | 决定河道、湖泊和洪泛区 |
| **GeographicTemperature** 最终地理温度 | BaseTemperature + 小尺度区域扰动 + 地形/静态气候修正 | 固定 | 群系、天然雪冰、生态基础 |
| **SoilMoisture / SurfaceMoisture** 土壤与地表湿度 | StaticPrecipitation + Height + River/Lake + 地表状态 | 可变化 | 植物、农业、泥地和局部生态 |
| **Biome** 群系 | GeographicTemperature + StaticPrecipitation + Moisture + Height + 水文 | 天然基线固定 | 沙漠、森林、草原、雪原等分类结果 |
| **NaturalSnow / Ice** 天然雪冰 | GeographicTemperature + 天然水体 | 天然基线固定 | 初始雪层、冻河、冻湖 |
| **VegetationBaseline** 天然植物分布 | Biome + 温度 + 水分 + Height + 水文 | 初始固定 | 草、森林、灌木、天然作物等初始生态 |
| **AnimalEcology** 动物生态 | Biome + 植被 + 生态规则 | 会变化 | 动物出生、死亡、迁移等 |
| **NaturalResources** 天然资源 | Height + Biome + 水文 + 资源规则 | 初始固定，可被开采 | 地表资源、矿物等 |
| **SeasonalTemperatureOffset** 季节温差 | SeasonCalendar + 日历/季节进度 | 会变化 | 叠加到当前环境温度 |
| **Weather** 天气状态 | 静态气候 + 世界时间 + 天气系统 | 会变化 | 降雨、降雪、雾、天气温差等 |
| **RuntimeWind** 当前风 | StaticWindField + `PlanetData.WindStrength` + Weather | 会变化 | 当前风力和表现；静态风向仍来自2级生成结果 |
| **SeasonalSnow** 季节积雪 | GeographicTemperature + 季节 + Weather | 会变化 | 降雪、积雪和融化 |
| **RuntimeTemperature** 当前环境温度 | GeographicTemperature + 星球运行时偏移 + 季节 + Weather + 局部热源 | 会变化 | 玩家、生物、物质的实际环境温度 |
| **LocalEnvironment** 局部环境 | 1/2级基线 + 液体 + 建筑 + 火源 + 玩家行为 | 会变化 | 局部热量、污染、水分等最终玩法状态 |

### 3级固定与动态的边界

3级不是“全部都会变化”。应区分两种数据：

1. **天然基线结果**：河流、天然湖泊、天然群系、初始植被、天然资源等，世界首次生成后作为确定性基线。
2. **运行时状态**：天气、季节温差、当前风、积雪、土壤含水量、局部冷热源、污染、生态数量等，可以随着时间和玩法变化。

运行时状态可以覆盖或改变玩家看到的世界，但不得反向修改1级原始世界常量和2级静态世界派生场。

## 6. 总依赖关系

```text
┌────────────────────────────────────────────┐
│ 1级：原始世界常量                          │
│ Seed / Topology / WorldSize                │
│ CoordinateScale / HeightProfile / SeaLevel │
│ PlanetTemperatureBaseline                  │
└───────────────────┬────────────────────────┘
                    ↓
┌────────────────────────────────────────────┐
│ 2级：静态世界派生场                        │
│ Height / Latitude / Land-Ocean             │
│ BaseTemperature                            │
│ StaticWindField / StaticPrecipitation      │
│ Drainage / Watershed                       │
└───────────────────┬────────────────────────┘
                    ↓
┌────────────────────────────────────────────┐
│ 3级：最终环境 / 生态状态                   │
│ River / Lake / Biome / NaturalSnow         │
│ Vegetation / Animals / Resources           │
│ Weather / RuntimeWind / SeasonalSnow       │
│ RuntimeTemperature / LocalEnvironment      │
└────────────────────────────────────────────┘
```

禁止形成以下反向依赖：

```text
沙漠 → 降低降水 → 更加沙漠
森林 → 增加基础降水 → 更容易成为森林
雪原 → 强制基础温度变低 → 更容易成为雪原
天气 → 修改静态气候基线
玩家火炉 → 修改世界生成温度
```

正确方向应始终是：

```text
原始世界常量
  ↓
静态世界派生场
  ↓
最终环境 / 生态状态
```

## 7. 与当前 TerraFlat 的对应关系

| 当前概念 | 目标层级 | 处理方向 |
| --- | --- | --- |
| `WorldSeed` | 1级 | 保持 |
| `TopologyMode / Radius / ChunkSize` | 1级 | 保持，明确其世界拓扑职责 |
| `world.coordinateScale` | 1级 | 保持 |
| `terrain.height.*` | 1级规则 | 保持；实际 `height` 属于2级 |
| `terrain.seaLevel` | 1级 | 保持 |
| `PlanetData.GlobalTemperature` | 当前职责混合 | 后续应区分固定星球温度基准与运行时温度偏移 |
| `climate.equator.* / climate.polarBand.*` | 1级固定配置 | Wrapped 世界用于生成纬度温度基线 |
| `climate.wind.*` | 1级固定配置 | 生成2级固定种子区域风场 |
| `climate.temperature.*` 噪声 | 2级静态气候 | Infinite 世界作为基础温度；Wrapped 世界主要作为区域温差扰动 |
| `climate.precipitation.*` 噪声 | 2级静态气候 | 当前是静态降水的基础值 |
| `climate.orographic.*` | 1级固定配置 | 用静态风向和逆风高度修正最终静态降水 |
| `climate.ocean.moistureFloor` | 1级固定配置 | 只保证海洋格环境湿度下限，不代表海洋向大气输送水汽 |
| `temperature.celsius` | 2级/3级边界 | 生成地理温度应固定；季节、天气、局部热源不得写回该基线 |
| `biome.*` 阈值 | 3级分类规则 | 只能消费气候和地形结果，不能反向生成气候 |
| `WeatherMgr` | 3级运行态 | 只叠加当前天气影响 |
| `SeasonalSnow` | 3级运行态 | 保持动态覆盖，不修改天然地理基线 |
