# 雪地脚步素材鸣谢

《4 dry snow steps》 — Iwan "qubodup" Gabovitch — [OpenGameArt 原始发布页](https://opengameart.org/content/4-dry-snow-steps) — [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)。

使用位置：FlatWorld 的 `player.footstep.snow`，三种雪地脚步变体，分别使用原包 `snow_step_dry-01.flac`、`snow_step_dry-03.flac`、`snow_step_dry-04.flac`。这些是真实采样，原作者在 2008/2009 年冬天于德国柏林录制并于 2009 年整理发布。

修改说明：将原始 44.1 kHz 立体声 FLAC 转成 48 kHz 单声道 PCM16 WAV，清理极低频、轻压孤立尖峰、统一提高增益并限制峰值、添加极短首尾淡化和末尾静音，整理成 0.45 / 0.51 / 0.49 秒的单步声；原始录音和授权说明保留在 `Sources/`。游戏根据实际积雪深度调整音量和音调。
