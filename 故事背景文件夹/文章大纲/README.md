# 分卷文章大纲

本目录是《FlatWorld》同名外传小说的**现行逐卷写作大纲**。每个文件为一卷，每个 `第XX章` 对应一项关键技术或一项不可替代的工程验证。旧版 [文章大纲](../文章大纲.md) 仅作素材，不再提供现行剧情。

## 不可越过的设定

- 故事当前只有玩家／主角一名现存智慧生命；没有部落、伙伴、工匠、后代、船员或活着的外星导师。
- 主角可无限复活，但技术、时间和设备不会因死亡自动重置；复活地点、间隔等尚未定稿，章节不能擅自指定规则。
- 早期只能依赖手工，随后用机械化、程序控制和非人格化自动化填补劳动力缺口。发现比邻星资料前，不出现可与主角自然对话的 AI。
- 比邻星文明已灭绝，只留下资料；用其训练出的首代 AI 只对形式化命题作“成立／不成立／证据不足”判断，不成为第二名智慧生命。
- 从“光帆探测器”到“载人恒星际飞船”必须区分有效载荷、制动、通信、寿命与补给；从“反物质”到“曲速”属于逐步增大的科幻假设，不伪装成现成技术。

## 科学与虚构的边界

引力弹弓、太阳帆、原位资源利用与核电推进有现实工程参照；冬眠用于人类深空飞行仍属研究设想，反物质推进和曲速飞船远未成为可用航天工程；“宇宙边缘／超越宇宙膨胀”是本作自定义规则，不是现实宇宙学结论。
