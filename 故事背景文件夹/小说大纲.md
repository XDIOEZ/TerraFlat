# FlatWorld 同名外传小说大纲

## 一、作品定位

- **作品性质**：游戏《FlatWorld》的同名外传小说。
- **题材类型**：原始社会生存、文明发展、星球探索、宇宙史诗、哲学科幻。
- **叙事跨度**：从主角穿越到原始社会开始，直到文明抵达宇宙边缘并触发“上帝的还原判定”。
- **核心卖点**：主角不是直接获得无敌力量，而是依靠知识、观察、协作和一代又一代人的积累，让一个原始部落逐步走向能够探索宇宙的文明。
- **故事基调**：前期重生存与部落冲突，中期重文明建设与社会选择，后期转向星际探索和宇宙终极谜题。

## 二、一句话梗概

一个来自现代社会的普通人穿越到陌生行星的原始时代。他从火种、食物和文字开始，带领族群一步步建立文明；当这颗星球的文明终于制造出能够超越宇宙膨胀的飞船，并抵达宇宙边缘时，他们发现所谓的宇宙尽头并不是虚空，而是一条等待文明触发的“上帝还原判定”。

## 三、核心设定

### 1. 穿越

主角穿越到一颗尚未进入文明时代的行星，醒来时被原始部落救下。这里没有现成的现代工业体系，主角拥有现代人的知识记忆，却没有现代社会的工具、能源和生产条件。

穿越原因暂不揭示。前期只留下三个异常：

1. 夜空中的星辰排列与主角记忆中的宇宙不同。
2. 行星地表存在无法解释的规则性遗迹。
3. 某些自然现象像是在重复已经发生过的历史。

### 2. 世界与星球

故事发生的星球暂名为“新世界”。它拥有海洋、荒原、森林、山脉和极端气候，也拥有尚未被现代文明理解的地下资源与远古遗迹。

这颗星球并非普通意义上的孤立行星，而是一个拥有完整历史周期的文明试验场。主角所在的原始社会只是当前周期的起点。

### 3. 宇宙膨胀与飞船速度

本作将“宇宙膨胀”设定为一种会改变空间尺度和因果距离的宇宙背景规则。后期文明制造的飞船并不是简单地用常规引擎加速，而是通过操纵局部空间尺度，使飞船的有效航行速度超过宇宙膨胀对航道的拉伸速度。

因此，“超过宇宙膨胀”不是一句普通的速度记录，而是文明第一次从宇宙内部规则中挣脱出来，开始接近宇宙边界。

### 4. 宇宙边缘

宇宙边缘不是一堵可以用肉眼看到的墙，而是宇宙规则的终止面。接近那里时，空间、时间、光线和记忆会逐渐失去稳定性，飞船记录的数据会出现互相矛盾的结果。

抵达宇宙边缘意味着文明已经触碰到创造这个宇宙的底层限制，也意味着它将被更高层级的规则识别。

### 5. 上帝的还原判定

“上帝”可以是创世者、宇宙管理者，也可以是高于宇宙的自律系统。其真实身份留到后期揭示，不在前期直接定论。

“还原判定”不是传统意义上的神罚，而是一项自动触发的宇宙级协议：当某个文明突破宇宙边界、开始接触创世层信息时，系统会判断该文明是否已经偏离初始设定。

判定启动后，宇宙可能被还原到最初状态；所有文明、历史和记忆都有可能被抹除，只留下下一轮循环的起点。

## 四、主角设定

- **姓名**：待定。
- **原身份**：现代社会的工程技术从业者，具备基础物理、机械、材料和生存常识，但不是全知全能的科学家。
- **最大优势**：知道文明发展的大致方向，能够把复杂问题拆解为可执行的小步骤。
- **最大弱点**：无法凭记忆复原完整工业体系，也无法单独解决组织、信任、资源和权力问题。
- **核心变化**：从“想把现代文明复制出来的人”，成长为“接受文明必须由所有人共同创造的人”。
- **最终选择**：在还原判定启动后，主角必须在保存现有文明、接受宇宙重置、或让文明以新的形式延续之间做出选择。

## 五、主要人物关系

### 1. 部落首领

最初救下主角的人。首领重视部落的生存，不相信无法验证的宏大理想，是主角最早的保护者，也是第一个要求主角证明自己的人。

### 2. 原始社会的伙伴

与主角一起学习、狩猎、种植和制造工具的人。他/她代表本地人的视角，提醒主角：知识并不等于正确，改变也可能伤害原有的生活。

### 3. 第一代反对者

认为主角带来的技术会破坏部落秩序，主张维持祖先留下的生活方式。其立场不完全错误，后期会成为主角反思“文明是否必然进步”的重要镜子。

### 4. 文明继承者

主角晚年或后代时期出现的关键人物。他们没有亲眼见过最初的原始时代，却把主角留下的方法发展成真正属于这个星球的文明。

### 5. 宇宙边缘的观测者

在后期出现的神秘存在，可能是上一个文明周期的残留意识，也可能是“上帝的还原判定”在宇宙中的执行节点。

## 六、故事分卷大纲

### 第一卷：火种之下

主角穿越到原始社会，在饥饿、寒冷、野兽和部落冲突中求生。为了获得留下来的资格，主角从最基础的火种、石器、陷阱和食物保存开始证明自己。

本卷重点不是快速改变世界，而是让主角明白：现代知识必须先被翻译成这个时代能够理解、制造和维护的东西。

**阶段节点：**

- 被原始部落救下并学习当地语言。
- 解决稳定取火、饮水、食物保存和简易住所问题。
- 因技术分配引发部落内部的第一次争执。
- 发现第一处不属于原始时代的规则性遗迹。
- 主角正式成为部落的一员，而不是暂时的外来者。

### 第二卷：种子与陶土

主角开始推动定居、种植、驯养和陶器制造。食物变得稳定后，人口增加，资源分配、土地归属和首领权力的问题也随之出现。

主角第一次意识到，技术不会自动带来幸福；每一项发明都会重新分配权力。

**阶段节点：**

- 建立可持续的食物来源。
- 制造陶器、纺织品和简单工具。
- 建立最初的记号、计数和季节记录。
- 与邻近部落发生贸易或冲突。
- 在“公开知识”与“保护部落优势”之间作出第一次选择。

### 第三卷：铜与文字

部落联盟形成，城市雏形出现。金属冶炼、文字、历法、道路和水利让主角推动的知识开始脱离个人，变成能够被后人继承的文明制度。

与此同时，主角发现这个世界的遗迹并不是偶然存在，而是曾有文明走过相似的道路。

**阶段节点：**

- 找到矿脉并建立早期冶炼体系。
- 发明更稳定的文字和档案制度。
- 建立学校、工坊与公共粮仓。
- 第一次出现围绕技术和知识的政治斗争。
- 远古遗迹留下“文明循环”的证据。

### 第四卷：蒸汽与电光

文明进入工业化阶段。机械、能源、交通和通信迅速发展，原始时代的部落已经变成拥有国家、城市和复杂阶层的社会。

主角不再是所有发明的中心，而成为制度和方向的守护者。新的文明继承者开始质疑主角的理念，认为探索未知不应受到旧道德的限制。

**阶段节点：**

- 建立大规模能源和工业体系。
- 形成跨区域交通与通信网络。
- 发射第一枚突破大气层的探测器。
- 发生一次由技术扩张引起的生态或战争危机。
- 社会开始讨论“文明发展的终点是否存在”。

### 第五卷：行星之眼

文明把目光从地表转向整颗星球。轨道空间站、月面基地、深海设施和极地观测站相继建立，人类第一次以外部视角观察自己的家园。

在探索行星的过程中，文明发现这颗星球的地质结构和遗迹分布都存在人为设计的痕迹。主角逐渐怀疑，自己穿越到这里并不是随机事件。

**阶段节点：**

- 建立近地轨道基地。
- 完成行星环境测绘。
- 找到远古文明留下的航天设施。
- 解读第一份关于“宇宙边界”的残缺记录。
- 确认行星所在的宇宙存在周期性重置痕迹。

### 第六卷：离开行星

文明完成真正意义上的深空飞船。不同国家、集团和学派围绕星际探索的目的发生冲突：有人想寻找资源，有人想寻找造物主，有人只想逃离即将到来的文明危机。

主角与新一代探索者共同组建远航计划，目标从“探索邻近星体”逐渐变成“寻找宇宙规则的边界”。

**阶段节点：**

- 建立可长期封闭运行的深空飞船。
- 探索多个行星和恒星系统。
- 发现不同星域的文明遗迹都在某个阶段突然中断。
- 证明宇宙膨胀会阻断普通意义上的远距离航行。
- 开始研究能够对抗空间尺度拉伸的推进技术。

### 第七卷：超越膨胀

文明终于制造出新型飞船。它不再单纯依靠燃料推动船体，而是改变飞船与空间的关系，使飞船的有效航行速度超过宇宙膨胀对航道的拉伸速度。

这项技术让文明第一次能够追赶那些原本永远远离自己的星系，也让他们看见宇宙正在隐藏的结构。

**阶段节点：**

- 第一次成功进行超越膨胀的短距离试航。
- 船员发现飞船外部的时间与内部记录出现偏差。
- 越过一条无法被普通望远镜观测的空间分界。
- 接收到来自宇宙边缘的重复信号。
- 所有仪器同时出现“还原倒计时”或类似的异常信息。

### 第八卷：宇宙边缘

远航舰队抵达宇宙边缘。那里没有传统意义上的黑暗，也没有所谓的宇宙外部，只有一片不断回写、修正和删除信息的规则层。

主角终于得知：他们走过的文明发展道路并非第一次发生。过去的文明也曾抵达这里，但在触发判定后被还原，所有努力只剩下无法被下一轮文明直接读取的碎片。

**阶段节点：**

- 飞船无法再用旧有物理定律描述自身状态。
- 船员看到不同历史版本中的自己。
- 远古遗迹、穿越事件和宇宙异常被串联起来。
- “上帝”以规则、声音、光或人格化使者的形式出现。
- 文明被告知：继续前进将触发宇宙还原判定。

### 第九卷：还原判定

上帝的还原判定正式启动。判定内容不是判断主角一行人的善恶，而是确认这个文明是否已经越过了允许存在的边界。

宇宙开始局部回退：城市消失，历史顺序颠倒，死者短暂归来，旧时代的语言重新覆盖新语言。主角必须在极短的时间内决定，是否牺牲远航舰队，把文明的全部记忆写入宇宙边缘；或者接受还原，让一切重新开始。

**最终冲突：**

- 文明是否有权拒绝创造者设定的边界？
- 被还原的文明是否仍然算真正存在过？
- 如果所有历史都会重置，发展和探索还有没有意义？
- 主角要拯救的是当前文明、未来文明，还是“文明能够继续选择”的可能性？

## 七、结局方向（待定）

### 方案 A：还原中的火种

主角无法阻止宇宙还原，但将文明的核心记忆隐藏进最初的火种、语言或星空图案中。下一轮原始社会里，一个孩子在夜晚抬头，看见了不属于这个时代的星座。

### 方案 B：拒绝判定

主角利用穿越能力与宇宙边缘的规则漏洞，拒绝接受还原。代价是现有宇宙失去稳定，主角和远航者必须成为新的宇宙边界守护者。

### 方案 C：完成真正的超越

主角发现“上帝”并不是宇宙之外的神，而是上一轮文明留下的自律系统。文明通过理解并改写还原协议，创造出不再依赖循环重启的新宇宙。

## 八、主题表达

1. 文明不是某一个天才的作品，而是无数普通人把知识继续传下去的结果。
2. 技术进步会扩大选择，也会扩大责任。
3. 所谓宇宙终点，可能只是更高层规则的入口。
4. 即使历史最终被还原，曾经做出的选择仍然改变过当时的人。
5. 真正的超越不是飞得更快，而是让文明拥有面对终极答案后继续选择的能力。

## 九、待补充事项

- 主角姓名、年龄、原世界身份。
- 穿越的具体原因和触发条件。
- 行星名称、生态环境与原始部落名称。
- 主要伙伴、反派和文明继承者的详细人物弧光。
- 游戏《FlatWorld》既有设定与小说设定的对应关系。
- “上帝”的最终形态和还原判定的具体规则。
- 最终采用哪一种结局，或将三种方案组合成开放式结局。
