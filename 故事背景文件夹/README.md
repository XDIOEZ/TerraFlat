# FlatWorld 同名外传小说

本目录用于创作游戏《FlatWorld》的同名外传小说。

小说与游戏可以共享世界观、历史背景和核心设定，但正文以独立故事为主；除非明确标注为既定设定，否则本目录中的内容均视为小说创作稿，不直接改变游戏内设定。

## 写作文件

- [小说大纲](./小说大纲.md)：当前有效的单人穿越、无限复活设定，以及技术主线和结局方向。
- [分卷文章大纲](./文章大纲/README.md)：现行二十二卷；每卷一个 Markdown 文件，每项关键科技独立成章。
- [旧版文章大纲](./文章大纲.md)：早期八十四章草稿，仅作技术素材，不作为现行剧情。
- [FlatWorld 同名外传小说](./FlatWorld同名外传小说.md)：小说正文与章节草稿。

## 目录约定

- 故事正文、章节草稿和场景片段统一使用 Markdown 文件。
- 新增人物、地点、组织或历史事件时，优先在正文之外留下简短设定记录，避免前后矛盾。
- 与游戏现有设定发生冲突时，在定稿前标记冲突，不直接覆盖游戏开发资料。
