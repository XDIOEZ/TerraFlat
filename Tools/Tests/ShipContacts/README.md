# 飞船散落物接触离线回归

在仓库根目录运行：

```powershell
dotnet run --project Tools/Tests/ShipContacts/ShipContacts.Tests.csproj -c Release
```

项目直接编译生产 `ShipCollisionSimulation`、`ShipSurfaceContacts`、`ShipAssemblyCache`、`ShipDockingService`、船体模型和宇宙运动领域类，没有复制碰撞或冲量实现，也不连接、启动或暂停 Unity。

覆盖范围：

- 157 件太空散落物遇到 175 部件的地表船时，拒绝解码、计重或重建碰撞整体；预热后连续 15700 次真实接触入口调用分配 0 字节。
- 166 件同在太空但离船数千米的残骸，连续16600次入口调用不解码、不计重、不重建整体，分配0字节；移到船旁立即恢复接触。
- 近处候选连续10000次复用真实碰撞容器且无分配；快速船跨越散落物时保留完整扫掠与动量传递。
- 太空物品碰撞继续向船传递冲量并写回飞行记录；连续两件物品读取刚写回的船速，稳定拓扑复用独立接触缓存。
- 不同地表和不相交高度跳过接触，同地表同高度继续阻挡物品。
- 新增船、飞行 Phase 改变，以及对接连接和断开后，筛选和整体缓存立即反映当前数据。
- long 极值附近的邻区散落物正常向船传递冲量；跨区船体真实矩形重叠正常分开，极远星区相同局部坐标不会碰撞，多次成对查询仍保留亚米局部位置。

`TestDoubles.cs` 只提供会话数据、Unity 数值类型、解码和重量读取的计数替身。计重使用固定 2 kg，不验证正式库存重量算法。场景降落、燃料消耗和控制台确认入口若被调用会抛异常。碰撞回归直接调用公开接触入口；连续冲量用入口自身在未捕获固定步姿态时的生产后备路径，不证明完整固定时钟顺序、Unity 物理表现、实际帧率、GC 停顿或游戏内手感。正式游玩验收由使用者完成。
