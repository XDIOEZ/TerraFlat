# 矿石小行星离线回归

运行 `python Tools/Tests/OreAsteroids/verify.py`。脚本在系统临时目录生成工程，直接编译正式小行星目录、状态、星区生成、引力与起降领域源码，使用当前两份太空 JSON；不连接 Unity，不影响 PlayMode。

覆盖确定性矿带、不同矿物和数量范围、非法配置、非致命伤害、掉落未准备时拒绝致死、击碎幂等、损伤与耗尽的 JSON 往返，以及三类大型小行星的真实引力构造、降落范围、接触身份和起飞速度继承。

环境替身仅补充 Unity 值类型、资源入口、序列化标记；不会模拟武器桥接、原生碰撞、实际库存拾取、场景迁移或活跃地表采矿。这些仍需未占用的 Unity 运行 Lua 验证。
