# 木盾与副手验证

`python Tools/Tests/ShieldActions/verify.py --build`

独立 CLR 直接链接正式 `ShieldActionClock` 与临时防御租约代码，覆盖单击/长按边界、盾击与弹反窗口、冷却、防御不持久化、来源组合、重复释放和跨生命周期释放。只替代 Unity 外壳，不复制生产算法。

资源检查包括输入动作与生成包装一致、Q 无重复绑定、5/10/10 防御、0.5 移速、无常驻装备防御、Prefab 引用与 Addressables。外部编译输出到 Temp，不暂停、刷新或退出 Unity。

正式 Lua：`GameplayTests/Systems/Combat/shield-rules.lua`，登记到 Combat 规则套件。需在允许的 Unity 测试环境执行；独立测试不等价于 Unity 运行验证。

运行验收：制作/GM 获取 `Shield_Wood`，放入快捷栏后短按左键前砸，长按举盾，松开恢复；放入装备面板副手槽后 Q 弹反。换槽、卸盾、死亡、翻滚和世界迁移均不得残留防御/减速。两客户端分别验证空主手副手弹反、远端举盾减速、盾击只命中一次及他人可见动作。

暂定可调参数：长按阈值 0.2 秒、盾击 0.3 秒/5 点钝击、弹反窗口 0.2 秒/冷却 0.6 秒；制作 6 木棍 + 2 麻绳。用户指定的三种防御值与举盾移速独立保存在盾牌 JSON 参数中。
