# 太空巡航离线回归

在仓库根目录运行：

```powershell
dotnet run --project Tools/Tests/SpaceCruise/SpaceCruise.Tests.csproj -c Release
```

需要 .NET 8 SDK，直接编译项目中的巡航引导、对接、拓扑缓存与光纤生产代码，不启动、暂停或刷新 Unity。

覆盖速度上限、反向刹车、部分燃料推进、不同固定步长和初速度的到点停车、最短转向、星体近侧安全航点、实时质量与动量、对接断开与接口损坏、碎片接口重新归属、光纤断开修复，以及稳定拓扑和光纤工作区的热路径分配。

末尾输出相同船体输入下重复重建与缓存刷新各 1000 次的耗时、线程分配量。耗时会受机器负载和运行时预热影响；该结果仅针对这些算法，不是游戏帧率或整个太空系统的内存占用。

`TestDoubles.cs` 只替代非测试目标的 Unity 资源入口、流体状态占位与控制台存在检查；未模拟完整机器供能、燃料库存、场景迁移或 Unity 物理。起飞、降落、导航交互、语言切换与船体碰撞仍需真实场景检查。
