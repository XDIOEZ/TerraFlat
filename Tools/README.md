# 开发工具导航

| 目录或文件 | 用途 |
| --- | --- |
| `Art` / `imagegen` | 美术处理与生成工具 |
| `ContentAudit` | 内容审计与离线数据检查 |
| `GameplayTesting` | Lua 测试选择、运行、报告和视觉复核 |
| `Tests` | 各系统的离线专项验证 |
| `Rendering` | 渲染诊断工具 |
| `FlatWorldModSDK` | MOD 构建与 SDK 工具 |
| `Windows` / `VSCode` | 开发环境辅助工具 |
| [ReferenceSamples](ReferenceSamples/README.md) | 已移出 Unity 导入和编译范围的第三方示例 |
| `Demos/Web/PelicanBike` | 两份独立网页演示，可直接用浏览器打开 |
| `UnityLayouts/FlatWorld.wlt` | 保存的 Unity 布局；在 Editor 的 Layout 菜单中加载 |
| `UnityMcpFast.py` | 读取当前配置并直连 Unity MCP |

验证证据和需要保留的审计清单放在 [开发文档/90_测试验证](../开发文档文件夹/90_测试验证)。临时输出使用根目录的 `outputs` 或 `.codex-tmp`，不混入源码目录。
