# 食物数值设置面板使用指南

## 概述
食物数值设置面板是一个编辑器工具，用于统一管理和设计游戏中所有食物的参数，包括营养值、腐败配置等。

## 打开面板
菜单路径：`FlatWorld -> 食物数值表`

## 功能说明

### 工具栏
- **扫描 Prefab**：自动扫描项目中所有包含 `Mod_Food` 组件的预制体，并添加到表格中
- **应用全部**：将表格中所有行的数据应用到对应的预制体
- **保存表格**：保存当前表格配置到 `FoodStatTableConfig.asset`

### 过滤栏
- **搜索**：按预制体名称或路径搜索
- **仅营养**：只显示包含营养数据的行
- **仅腐败**：只显示启用腐败配置的行

### 表格列说明
| 列名 | 说明 |
|------|------|
| Prefab | 预制体引用 |
| 碳水/脂肪/蛋白/水/维生 | 五种营养值 |
| 进度 | 最大进度（咀嚼次数） |
| 消耗速度 | 营养消耗速度 |
| 腐败 | 腐败配置状态（启用/禁用） |
| 状态 | 该行的特征标记（营养/腐败/无数值） |

### 行操作按钮
- **应用**：将该行数据应用到对应预制体
- **定位**：在项目面板中定位到该预制体
- **Inspector**：打开预制体编辑阶段，定位到 `Mod_Food` 组件

### 底部功能
- **应用选中行**：只应用当前选中行的数据
- **从 Prefab 重新扫描**：重新扫描所有预制体
- **清空表格**：清空当前表格中的所有行

## 工作流程

### 添加新食物到表格
1. 确保新食物预制体中有 `Mod_Food` 组件
2. 点击"扫描 Prefab"按钮
3. 新食物会自动出现在表格中

### 修改食物参数
1. 在表格中找到要修改的食物行
2. 直接编辑表格中的数值字段（不需要按回车，自动保存）
3. 修改会自动保存到表格配置文件
4. 点击"应用"按钮将修改应用到预制体

### 批量应用
1. 修改表格中的数据
2. 点击"应用全部"按钮
3. 所有数据会同时应用到对应的预制体

## 可配置参数

### 营养参数
- **碳水化合物**：Carbohydrates（主要能量来源）
- **脂肪**：Fat（备用能量来源）
- **蛋白质**：Protein（生命恢复）
- **水分**：Water（生存必需）
- **维生素**：Vitamins（健康维持）

### 食物特性
- **进度**：咀嚼多少次才能完全吃掉（Max_EatingProgress）
- **消耗速度**：营养值消耗的速度倍率
- **水份消耗倍率**：水份独立消耗速度
- **营养消耗倍率**：总体营养消耗倍率

### 腐败配置
- **启用腐败**：是否启用腐败机制
- **腐败间隔**：多少秒后触发腐败（秒）
- **腐败目标**：腐败后转变成的物品ID（如 "Meat_Rotten"）

## 配置文件位置

- **行数据类**：`FoodStatTableRow.cs`
- **窗口类**：`FoodStatTableWindow.cs`
- **配置类**：`FoodStatTableConfig.cs`

## 技巧

### 快速修改
直接在表格中编辑数值，修改会立即保存到配置文件。

### 对比原值
如果预制体中已有参数，扫描时会自动读取并填充到表格中。

### 批量导入参数
可以先修改一个食物的预制体参数，然后扫描更新表格。

## 常见问题

### Q: 表格中找不到某个食物预制体？
A: 确保该预制体包含 `Mod_Food` 组件，然后点击"扫描 Prefab"按钮。

### Q: 修改了表格数据但预制体没有更新？
A: 需要点击该行的"应用"按钮或点击"应用全部"按钮。

### Q: 如何删除表格中的行？
A: 暂不支持单行删除。可以点击"清空表格"后重新扫描想要的预制体。
