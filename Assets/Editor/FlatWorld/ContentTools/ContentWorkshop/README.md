# FlatWorld 内容工坊

## 打开方式

- 在 Unity 顶部菜单选择 `FlatWorld > 内容配置 > 内容工坊`。
- 工具直接读取 `StreamingAssets/GameConfig` 下由 Manifest 启用的物品与配方分包；JSON 仍是运行时唯一真源。

## 工作区

- **滚动列表合成**：从带图标的物品图鉴选择材料，加入不限长度的滚动清单。支持材料数量、零消耗工具、标签材料和多产物，普通合成始终按材料身份与总量匹配。
- **熔炼与烹饪**：使用低温烹饪、炭化、高温熔炼、合金四个预设创建热加工配方，仍复用游戏现有 `smelting` 运行时协议。
- **创建游戏道具**：先选材料、食物、采集工具、近战武器、装备、种子或建筑召唤器模板，再配置玩家可见名称、图标、堆叠、耐久和主要能力。工具自动生成稳定 ID、继承关系、常用模块和 Sprite Addressables。

## 安全规则

- 保存前会校验整份启用目录，包括重复 ID、配方引用、物品继承与分包 `shellPrefab` 边界；失败时不会写入 JSON。
- 窗口打开后如果目标文件被其他工具修改，会拒绝覆盖并要求重新加载。
- 每次写盘前在 `Library/FlatWorldContentWorkshop/Backups` 创建备份；该目录是本机临时恢复区，不进入版本控制。
- 普通合成材料清单没有条目上限；热加工仍使用 3×3 位置画布，已有更大热加工网格会拒绝载入，避免静默截断。
- 建筑召唤器模板复用帐篷行为，只适合快速制作同类道具；要创建全新建筑 Prefab，仍需先配置对应建筑资源和模块关联。
