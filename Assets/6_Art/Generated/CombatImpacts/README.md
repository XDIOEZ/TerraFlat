# 武器命中特效

资源类别为透明白色命中动画。切割继续使用现有 hit01；穿刺、钝击、劈砍由内置 ImageGen 分别生成。
三张源图保留生成 Alpha，1774×887，4 列×2 行，每格 443.5；Unity 导入上限 256，实际约 64×64/帧，Point、无 Mipmap、无压缩、中心 Pivot、PPU 443.5。
帧顺序从左到右、从上到下，约 0.28 秒播放一次，末尾为空帧；沿用 SlicingEffect 的武器方向采样和池化回收。

共同提示词：透明 RGBA，8 帧规则 4×2 网格，白色尖锐像素线条，快速出现、扩张、碎裂消散；无角色、武器实体、文字、地面、阴影、色彩或光晕。
穿刺提示词：向右的细长针状穿刺和两条短平行速度线。
钝击提示词：中心闪点、6–8 条短放射尖刺和碎裂的八角冲击环，不绘制盾牌。
劈砍提示词：从左上到右下的宽阔重斩楔形，内部留有细长裂隙，带少量尾部碎片。

类型选择由 CombatDamage.DominantKind 提供，CombatImpactEffects 资源维护唯一映射；不要把类型动画再次加入 AttackEffects 通用列表。
人工观感检查：连续攻击、四种主伤害武器、横竖斜向、夜间光照，确认形状可辨、中心稳定、没有残帧。
