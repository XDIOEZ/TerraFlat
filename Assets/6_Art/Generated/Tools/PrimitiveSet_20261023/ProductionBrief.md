# 全工具重绘制作约定

日期：2026-10-23。按前次清单重绘 35 款成品工具，并替换游戏内引用。只改美术和必要的美术引用/导入，不改玩法。主 Agent 负责整合、meta、Addressables 与引用；子 Agent 只写各自分配的图片和记录。

## 画风与像素锚点

先读 `.agents/skills/flatworld-art/SKILL.md`、`references/art-direction.md` 和内置 imagegen Skill。用户认可的颗粒锚点：`Assets/6_Art/Generated/Tools/StyleSamples_20261023/Shovel_Iron_StyleSample.png`。以它的粗像素为准，低饱和、偏写实、约 48×48 逻辑像素观感，硬边大像素簇，每种材质两至三档明暗，左上光源。画布像素数不等于逻辑像素数，不增加细木纹、碎高光或噪点。

## 关键用户要求

游戏从零发展科技。早期复合工具必须让人看出亲手削切、装配、绑扎的结构。工具头与木柄相接处画三四圈粗植物纤维绳或皮条，至少一个清楚的大结扣/交叉缠绕，承担实际固定作用；单在握柄上缠一圈不算完成。石器、青铜、铁各自保留材质身份，头部可以略不对称、粗铸或手锻。避免现代机制套管、螺丝、精细车削、完全规整的柄、连续抛光亮边。单体石片等无拼装关系的物品不硬加木柄或绳。

## 布局与导出

每件独立生成，一次调用只输出一件；不生成包含多个工具的合图作为生产素材。完整轮廓、真实透明 Alpha、每边留足 10% 透明留白、无背景/投影/文字/标签/手/人物。长柄默认从左下握柄到右上工具头，与现有样例同向；其他类型按结构辨识优先。不同材质的同类工具保持一致的尺度、像素颗粒和主体比例，但不要只给完全相同的图换色。

只用内置 image_gen；以旧图作身份参考、铁铲作粗像素参考，必须先 view_image。无需 CLI 或其他绘图工具，不用代码/脚本生成或修改图像。原始输出直接 Copy-Item 到新目录，保留源图不删。每件图保存为 `Assets/6_Art/Generated/Tools/PrimitiveSet_20261023/<ID>/<ID>_Icon.png`。不要改旧样例、配置、meta、Skill 或其他 Agent 的目录。

生成图必须用 generatedImage(result) 展示，不打印 base64。可同时进行最多两件独立生成，按 imagegen 约定使用 120000ms exec/wait 和约 48 秒 yield_control，避免长时间没有进度。工具失败记录实际错误并报告，不能算作完成。

## 记录与交接

每组将记录写入 `records-<group>.json`（主 Agent 整合）：每件含 id、name、finalPath、sourcePath、prompt、referencePaths、width、height；另记录调用失败或修订。不提交、不运行游戏、不切 PlayMode、不改暂存区。主 Agent 会统一创建本轮 commit。

火把绘制熄灭/未点燃的绑扎火炬，火焰由运行时燃烧模块表现；木制生火装置与手钻按实际定义表现其结构，不画成电动工具。剪刀保留剪刀功能，优先朴素锻制结构，不强加不可能的绳结锁死枢轴。
