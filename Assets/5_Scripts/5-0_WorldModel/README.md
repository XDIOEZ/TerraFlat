# 世界模型目录

同一程序集内按职责归类；命名空间继续使用 `FlatWorld.WorldModel`，Unity 表现宿主位于 `5-3_GamePlay/World/WorldModel`。

| 目录 | 内容 |
| --- | --- |
| `Core` | 世界运行体、快照、身份绑定、物品归属、共享租约和基础数值类型 |
| `Chunks` | 区块运行体、窗口调度与流送诊断 |
| `Terrain` | 区块地形及批量修改、支撑面、高度层与冻结水层 |
| `Liquids` | 液体身份目录和流动求解 |
| `Weather` | 区域天气、冻结气候、天气分布及空气湿度 |
| `Occupancy` | 区块占格与世界占格数据 |
| `Generation` | 确定性地形与生态生成、采样和冻结生成配置 |
| `Messaging` | 纯模型事件分发 |

根目录只保留程序集定义、程序集属性和本导航。一个类型的 partial 文件放在一起，不按文件后缀拆到不同目录。
