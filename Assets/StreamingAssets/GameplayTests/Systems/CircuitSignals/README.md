# 电路信号与自动化回归

- `rules.lua`：通过正式信号图与电网验证四门全部输入、同步传播、多源OR、拆除、断线、旋转、环绕及串联触点真实功率；无线同网收发回环按配置检查。
- `gameplay.lua`：隔离世界正式创建两个电网、双模式转换器、OR门、继电器和电灯，等待实际供电、断电、恢复与机器快照重建，并确认接收值初始为0。
- `rules.lua` 同时检查振荡器变步长、暂停、启停、频率量化与只保存配置；`gameplay-oscillator.lua` 通过正式放置和机器命令周期驱动继电器、电灯，并恢复配置快照。
- 信号源由设备业务提供；位值、继电器触点和无线来源均是可重建运行态，不入存档。
- 覆盖边界：现场建造使用正式 `MachineWorld.Place` 的GM前置，不代表玩家材料扣除、全部触屏布局、真实双端或SQLite退出重进已验收。场景结束保留正式截图供视觉复核。
- 振荡器本轮：快速Lua规则通过、32项EditMode前置通过；PlayMode启动被生态配置中Snake重复登记的既有Error阻断，无有效截图，不能据此标为游戏内验收完成。双端、完整退出读档及玩家材料/输入流程仍待验证。
