# 农业规则与现场回归

2026-10-15：本系统登记的快速规则和 PlayMode 入口均已执行通过，见 [缓存与全系统 DEBUG](../../缓存与38系统DEBUG循环_2026-10-15.md)。以下功能缺口继续有效，玩法验收由用户进行。

- 覆盖 `TileData_Farmland` 水肥补充/消耗上下限、负数拒绝和 `Clone` 后肥力对象隔离。
- `agriculture/surface_water_rule` 直接调用单格和批量共用的 `FarmlandSystem.TryCalculateSurfaceWater`，覆盖正常增加、容量截断、满水/浮点微小增量跳过、容量保底、零/负/NaN/正负 Infinity 补水拒绝；无变化和拒绝时核对原水量保持不变。
- `gameplay.lua` 在隔离测试世界选取附近干燥、无草、无作物、无既有农业记录的合格空格，执行正式分段耕作、灌溉/消耗提交，核对真实地形和农业差量；返回前恢复原格、水肥和草差量并移除自有农业记录。
- 播种和当前作物成长入口尚未公开独立事务，未覆盖种子扣除、真实成长、气候历史和一次性收获；培育仓属于农业业务，供电/机器调度作为跨系统依赖。
- 纯规则不触碰世界；运行态样本同步完成并恢复，因此只有数据断言、零截图。附近无合格空格时明确失败，不绕过正式资格规则。
- 共用补水规则断言不覆盖建筑占地、真实降雨到土壤的整条链、批量提交的实际调用路径或显示性能；环境批写数据/通知契约见 [环境规则](../Environment/README.md)。
