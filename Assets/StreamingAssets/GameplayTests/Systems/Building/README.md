# 建造规则与现场回归

- 覆盖 `TerrainSupportLayer` 添加有效支撑、通行成本/可走性、底层地形与液体保留，以及撤支撑后的恢复。
- 覆盖 `BuildingModuleStateTransfer.Copy` 从单件载体向建筑复制真实二进制模块载荷、保持目标元信息、隔离源状态、拒绝重复/缺失模块和堆叠状态载体。
- `gameplay.lua` 使用正式木墙召唤器、独立材料槽和真实 Tile 后端，记录写入/扣料后的发布阶段，再注入发布拒绝检查退料和撤墙；成功放置检查实际墙格和扣一份材料，重叠放置检查无额外扣料或写入。
- 运行态只选取无草、无农业记录的合格空格，结束通过正式拆除入口移除自有墙，并恢复原格和草差量。未覆盖 Item/机器建筑后端、拆回快照、门、输入预览和联机建造。
- 纯规则只持有一格领域地形；运行态同步恢复后返回，只做数据断言、零截图。附近无合格空格时明确失败。
