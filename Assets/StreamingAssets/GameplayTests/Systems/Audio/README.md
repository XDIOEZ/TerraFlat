# 音频

2026-10-15：本系统登记的快速规则和 PlayMode 入口均已执行通过，见 [缓存与全系统 DEBUG](../../缓存与38系统DEBUG循环_2026-10-15.md)。以下功能缺口继续有效，玩法验收由用户进行。

快速入口：`rules.lua`；操作：`audio/bus_volume、catalog_lifecycle`。

已编写的规则覆盖：AudioUserSettings 五总线与总音量范围；AudioPlayOptions 的全局和空间位置参数；JsonUtility装配独立 AudioCue/AudioCatalog、重复ID校验、目录索引重建与规范查询，随后释放临时资源。未创建全局 AudioService。

PlayMode 入口：`gameplay-suite.json` / `gameplay.lua`；操作 `audio/voice_lifecycle`。

真实流程覆盖：使用已入世世界的现有 AudioService/唯一启用监听器，播放正式湿衣循环和开门录音。仅复制 Cue 并改测试 ID 隔离冷却/并发身份，录音、总线、距离及播放池规则保留原值；拒绝抢占满池中其他来源的声音。检查真实 AudioSource 正在播放且有采样、完整空间混音/线性衰减参数、角色到监听器平面的投影、句柄倍率/主音量/总线音量即时生效、静音保留句柄及恢复、范围外短音不占池、范围外循环保留与实际位置、即时停止、复用同一声源以及旧句柄不能误停新声音。结束或失败仅停止本轮句柄，恢复原用户音量/静音，不写音频 PlayerPrefs。声音没有可解释的画面变化；PlayMode 仍由宿主按规则自动截图，声音正确性由数据断言检验。

设置保存/放弃与真实音量控件由 [UISettings 共用现场](../UISettings/gameplay-suite.json) 补充；本组集中检查音源运行链。

关键流程待补：设备实际听感、测量最终声压/立体声方向、淡入淡出时间推进、并发拒绝/抢占优先级、Mixer 路由、监听器解绑/重绑与场景迁移、声音设备缺失和暂停恢复。线性衰减参数和远声坐标断言不能证明硬件上实际响度正确。

本轮已编译并执行声源与句柄断言，未验收测试声音；听感和最终验收由用户执行。
