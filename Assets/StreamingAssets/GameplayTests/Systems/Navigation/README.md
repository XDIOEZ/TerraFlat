# 导航寻路系统

2026-10-15：本系统登记的快速规则和 PlayMode 入口均已执行通过，见 [缓存与全系统 DEBUG](../../缓存与38系统DEBUG循环_2026-10-15.md)。以下功能缺口继续有效，玩法验收由用户进行。

`rules.lua` 在独立 `WorldNavigationGrid` 上调用正式寻路、邻边代价、动态阻挡及失效通知，覆盖绕开高代价格、障碍绕行、预算不足、多个阻挡来源、移动占地、批量更新、区域删除和斜角防穿。

`chunk_block_pool` 通过 64 轮不同区块装卸验证导航块只创建一次，检查液深/代价不串块、已有动态阻挡仍生效，并验证池上限及切换世界释放缓存；不替代实际加载场景的帧时间测量。

`block_addressing` 覆盖 16×16 导航块的负坐标、整数极值、枚举和删除回归，另外对正式规范化格读取做 524,288 次隔离计时；计时只用于对比本地热路径，不代表游戏 FPS。

`navigation/avoidance_topology` 在独立规则中验证真实 GO 局部避让的九宫格桶寻址与单轮冻结拓扑，包括负格、非方形地图、跨环绕接缝和无限地图；不覆盖多生物真实拥挤与动作观感。

PlayMode 与 AI 共用 [AI/gameplay-suite.json](../AI/gameplay-suite.json)，案例只有一份：真实已加载世界的路径请求按严格代价上限异步拒绝，正式生物随后收到推进命令，实际导航代理取得路径并由真实 Tick 移动到达。Lua 检查已获得路径、位移/速度、沿途可走性、目标距离，以及取消时旧目的地、路径与等待请求均被撤销。

自有生物、路径请求和截图现场统一由 AI 夹具收尾，Lua 断言失败或中断时也释放，不另外创建重复现场入口。

缺口：建筑障碍绕行、玩家导航控制、门户长距离路线、共享流场拥挤和环绕边界场景。基础路径与一只生物移动不能证明这些场景通过。

历史规则运行见 [统一执行记录](../../执行记录与失败待办_2026-10-14.md)。共用现场已在本轮执行，验收由用户进行。
