## PlayMode执行器现场

入口 `gameplay-suite.json` 有两份按顺序执行的Lua：第一份登记同步与跨帧清理、实际等待并核对命令/回调顺序；第二份核对上份Lua已经完成两种清理并重新获得玩家控制。单选第二份缺少前置会明确失败，请按整个系统运行。

只创建自有内存租约，不修改正式游戏状态。尚未覆盖强制域重载、中断后世界退出、磁盘报告与截图宿主。本轮仅静态编写，未编译、未执行或验收。
