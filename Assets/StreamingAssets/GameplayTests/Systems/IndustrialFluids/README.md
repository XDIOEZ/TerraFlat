# 工业气液 V1 回归

工业规则只有物质身份、实际数量、固定容量、每秒速率。气液分网；普通管道、过滤管、阀门没有库存；每个罐独立保存。过滤仅取原混气中的指定组分，其他留源。自然补气上限默认20%，动力泵可充满。

液体地表接口按整份操作，因此液泵可保留不足一份的真实本地尾量，随设备保存/拆装；它不是管道容量。泵在剩余速率预算内送出尾量后继续抽下一份。装填机具有小设备输入缓冲和三个实际容器槽，0→1→2装满；不合适槽跳过。地面蒸汽机消费真实水族液体；铁路库存蒸汽引擎保持原能力。

规则入口：rules-suite.json。现场入口：GameplayTests/fluid-suite.json。共用库存热力学、内能和相变测试保留，工业管网本身不运行这些机制。

现场新采样覆盖：无库存拓扑/过滤/方向/阀门、独立罐拆装和倒序恢复、自然补气、动力泵、三槽气罐顺序装填、真实淡水抽取及尾量、气液出口、氢氧引擎和水引擎实际负载消费。

本轮离线数量/图12组已通过；正式Lua尚未运行（用户进入PlayMode，未打断）。缺口：真正的三槽UI拖放/取回、液体三槽端到端、直接泵→装填机/蒸汽机完整现场、多引擎竞争/空载饥饿、环形多路径并发、破坏第二组分异常回滚、双端权威、保存退出重启和视觉验收。新探针存在不代表这些流程已通过。
