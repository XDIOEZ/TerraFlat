# 工业气液 V1 回归

工业规则只有物质身份、实际数量、固定容量、每秒速率。气液分网；普通管道、过滤管、阀门没有库存；同类方块罐自然组合并共享容量/内容，按格容量保存份额。过滤仅取原混气中的指定组分，其他留源。自然补气上限默认20%，动力泵可充满。

液体地表接口按整份操作，因此液泵可保留不足一份的真实本地尾量，随设备保存/拆装；它不是管道容量。泵在剩余速率预算内送出尾量后继续抽下一份。装填机具有小设备输入缓冲和三个实际容器槽，0→1→2装满；不合适槽跳过。地面蒸汽机消费真实水族液体；铁路库存蒸汽引擎保持原能力。
