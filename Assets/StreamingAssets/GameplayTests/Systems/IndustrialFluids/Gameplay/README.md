# 工业V1现场案例

- fluid_inventory / fluid_thermodynamics：保留共用库存事务与物性基础。
- fluid_state_save：铁钢气液罐自然组合、三格容量、断桥拆分/复装、单格份额与倒序恢复、异种液体隔离/排空后合并及模板整组补给。
- fluid_topology：只连接无库存、气液分离、阀门、方向、指定气体过滤。
- fluid_transport：混合气比例排放、0停用、速率保存。
- fluid_tanks：自然20%上限、三槽实际铁罐按顺序装填。
- fluid_pumps_compressors：普通气泵和地表液泵；最后独立创建5×4真实水池、同水域双电泵、液管、两只储罐和空电池铜线，结束图保留抽前现场，验证无电不抽水、共享寻源与正式机器表现进入镜头。
- fluid_surface_pump_after：独立重建相同现场，充入真实电池储能，由正常世界Tick供电和抽液，保留约1/10底水；断言双泵实际获电、两罐进水及水池/泵尾量/储罐总量守恒，结束截图后统一恢复现场和镜头。
- fluid_reactions：实际氢氧与地面蒸汽机；蒸汽机增加三燃料槽、非燃料拒绝、空槽/损坏拒绝点火、未点火无动力、火种三秒吸收后扣料、吸收中取回不增燃值、带载同时耗水耗燃料、燃尽自动熄火、熄火/缺水/缺氧停止供能且保留储备，以及快照保留槽位和燃值；无电解/化学过滤用例。
- fluid_environment：共用地表事务、液体出口及满格保源。

退役的压差、组主分摊、爆炸、压缩功和相变工业断言已删除，以对应简单规则替换。Lua持有断言，C#采样调用生产接口。未覆盖项与本轮执行边界见上层README；本轮因用户PlayMode未执行这些新现场案例。
