# 环境纯规则回归

2026-10-15：本系统登记的快速规则和 PlayMode 入口均已执行通过，见 [缓存与全系统 DEBUG](../../缓存与38系统DEBUG循环_2026-10-15.md)。以下功能缺口继续有效，玩法验收由用户进行。

- 调用 `ThermalRuntime` 检查升降温、结算步长、非法输入和目标限速；调用 `ThermalInfluenceRuntime` 检查距离衰减及重叠；调用 `WindEnvironmentRules` 检查风级/质量/重力门槛、四区混合、超重零风速及零权重边界。
- 在独立 `RegionalWeatherEngine` 内另覆盖区域成员共享、冻结代表气候、负坐标分区、降雨事件到期及统一/强风分段概率。
- 2026-10-17 新增但未执行 `natural_fog_profile、natural_fog_distribution、natural_fog_lifecycle、natural_fog_validation`：读取正式配置，覆盖温湿值对触发概率/强度时长上限的控制、独立升温/增湿、温度钳制、风雨不参与气候权重；穷举均匀输入网格核对强度抛物线分布、两端少中间多、强度/时长上下界及非法参数；独立引擎经自然检查起雾，检查区域共享、与降水并存、限时覆盖及零雾覆盖恢复、到期、清除、正式存档记录转换和客户端快照入口。按用户要求未编译、未运行；记录转换和纯副本入口不代表真实磁盘读写、联机或最终雾画面已验收。
- `wind_read_path` 比较正式单项风采样与完整天气快照，覆盖活动风事件、强制零风和到期恢复、无气候方向时的稳定回退、四区原始字段、客户端副本、环绕等价坐标、缺区只读及非法坐标；夹具带有雨和雷事件，避免单项查询依赖完整快照的其他天气字段。
- `thermal_point_path` 用独立局部来源和稀疏液体源比较正式单格/整块热场入口，覆盖温度/强度/位置/半径更新、移除、制冷、同温热源取最强、土壤不影响液体版本、支撑遮盖/恢复、抽干、卸载和同位置重绑，以及环绕缝。此用例检查数值和缓存失效契约，不以耗时阈值断言性能。
- `environment_batch、environment_batch_rejection、environment_batch_lifecycle、environment_batch_revision` 调用正式 `ChunkTerrainData` 批写接口，覆盖真实变化格与通知索引、空批/不变写、跨层先写后发、非法输入整批拒绝、故障后继续使用、观察者抛错后的待发队列重试、回调内写入/嵌套发布/释放拒绝，以及普通土壤、支撑面和液体缓存版本边界。批量索引和只读层在同步采样内复制成报告数值，不能跨回调或跨帧持有借用内存。
- 仅在独立夹具中登记来源，不改变真实世界的温度和天气。未覆盖随机抽签序列、真实天气保存/网络复制、地表雨雪积累、雷击伤害、湿度缓存、污染变化和玩家生存反馈。
- 批写回归覆盖数据与通知契约，尚未覆盖真实雨量转土壤水量、湿地 BRG 上传、建筑占地过滤、区块重绑和雨天耗时；只读借用不得跨帧保存是调用方契约，规则回归只检查同步回调保护。
- 本组是环境规则子集，没有截图，不能代替天气集成验收。
