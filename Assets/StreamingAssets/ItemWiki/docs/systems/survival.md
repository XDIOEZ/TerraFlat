# 生存系统

## 系统定位

负责玩家营养、水分、体力、氧气、体温以及这些资源对移动、战斗、回血和环境生存的影响。

## 当前组成

生存状态不是一个大模块，而是多个权威模块协作：

- `Mod_Food`：碳水、脂肪、蛋白质、水分、维生素及对应消耗/伤害/回血。
- `Mod_Stamina`：当前/最大体力、离散扣体力与难度倍率。
- `Mod_Oxygen`：水中漂浮、氧气和溺水。
- `Mod_Temperature`：基础体温、环境温度影响、入水降温与临时增温。
- `Mover`：移动/奔跑速度与移动相关体力、营养、水分消耗倍率。

## 玩家默认基础值

玩家创建模板位于 `GameConfig/Players/player-creation-manifest.json`。当前默认：

- 体力：100 / 100。
- 负重：最大重量 60，最大体积 90。
- 奔跑速度倍率：1.5。
- 奔跑基础体力消耗：2/秒。
- 初始水分：150 / 150。
- 初始碳水、脂肪、蛋白质、维生素均为 50。

## 氧气与水中生存

`Mod_Oxygen` 当前规则：

1. 进入真实水格后先持续消耗体力维持漂浮。
2. 体力仍大于 0 时氧气会恢复。
3. 体力耗尽后开始消耗氧气。
4. 氧气归零后通过 `DamageReceiver` 按基础 10 HP/秒持续结算溺水伤害。
5. 离水后氧气恢复。

模块默认参数当前为：体力 5/秒、氧气消耗 10/秒、氧气恢复 25/秒、溺水伤害 10/秒。

## 体温

- 环境温度统一通过 `TemperatureMgr.TryGetAmbientTemperature` 查询当前已加载地块。
- 玩家体温与环境温度、天气、局部冷热源、入水状态共同结算。
- 装备只能通过水体降温保护等公开通道提供修饰，不能直接写体温。
- Buff 临时增温按来源登记，不把临时增温写入基础体温存档。

## 营养与生命

- 玩家生命回复的蛋白质门槛来自玩家创建模板。
- 玩家处于死亡/濒死状态时，Food 等被动模块不能继续把生命抬回正数。
- 食物腐败与角色营养消耗是不同生命周期，库存食物不因为没有角色 Tick 就停止腐败。

## 修改时联动

- 体力武器成本：战斗。
- 环境温度、天气：环境。
- 水体地块：地图/维度。
- 装备保护：装备。
- 生存 HUD：UI。
